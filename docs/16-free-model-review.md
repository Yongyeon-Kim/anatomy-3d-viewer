# 무료 모델 재검토와 폐 외형 샘플

작성일: 2026-11-06. 연결 이슈: [#6](https://github.com/Yongyeon-Kim/anatomy-3d/issues/6). 사용자의 조건에 따라 유료 모델·유료 제작 의뢰는 제외한다. 무료 공개·비상업 모델을 사용 후보로 검토한다.

## 이번 결과

이미 확보한 Z-Anatomy의 Blender 파일에서 **폐 외형을 이루는 5개 메시**를 확인하고 OBJ로 추출했다. 이전 BodyParts3D PART-OF 샘플보다 장기의 바깥 모양을 설명하는 데 적합한 후보가 생겼다. 의학적 정확성이나 제품용 최종 품질을 승인한 것은 아니다.

Blender 3.6.23을 공식 배포처에서 받아 SHA-256을 확인했다. `--factory-startup --disable-autoexec`와 `use_scripts=False`로 열었고, 원본에 포함된 `z-anatomy.py`가 실행되지 않았음을 로그에서 확인했다. 모델 전체에는 7,184개 오브젝트가 있으며, 이름 검색 결과에는 면이 없는 표지용 메시도 있어 이름만으로 모델 존재를 판단하지 않았다.

## 추출 결과

| 소스 오브젝트 | 기본 정점 | 삼각형 |
| --- | ---: | ---: |
| Inferior lobe of left lung | 1,142 | 2,275 |
| Inferior lobe of right lung | 1,040 | 2,074 |
| Middle lobe of right lung | 914 | 1,818 |
| Superior lobe of left lung | 1,141 | 2,265 |
| Superior lobe of right lung | 968 | 1,910 |

합계 10,342개 삼각형, OBJ 350,599 bytes다. 이는 기본 메시의 측정이며 원본의 SUBSURF 보정은 적용하지 않았다. 원본 메시를 삼각형으로 변환하고 월드 좌표로 내보냈으며, 원본 Blender 파일은 수정하지 않았다.

[오브젝트 목록](../research/results/z-anatomy-inventory.json), [추출 기록](../research/results/z-anatomy-export.json), [형상 검사](../research/results/z-lungs-quality.json)를 저장했다. 같은 좌표 정점을 합쳐 검사한 결과 경계 모서리 합계 72개, 비다양체 모서리 합계 5개가 검출됐다. 위치가 의도된 개구부인지 형상 오류인지는 추가 검토가 필요하다.

## 시각 비교 판단

두 방향의 로컬 미리보기 `research/results/z-lungs-preview.png`를 생성하여 확인했다. 폐의 연속적인 외형과 엽 구분을 볼 수 있다. 기본 메시에서는 각진 면과 음영 변화가 보이므로 표면 보정·재질 개선을 별도로 검토한다.

미리보기는 기본 메시의 확인용이며 검사자가 정한 색과 조명을 사용했다. 원본 재질·사진 같은 질감을 완전히 재현한 것이 아니다. BodyParts3D와 해상도·축·범위가 다른 자료이므로 삼각형 수 차이를 곧바로 품질·성능 우열로 해석하지 않는다. 이번에는 BodyParts3D와 병합하거나 상대 좌표를 맞추지 않았다.

화면 위에는 출처 문구를 겹쳐 놓지 않았다. 해당 이미지는 공개 배포하지 않은 로컬 검토 자료이며 원본·출처·라이선스와 파생 이력은 폴더에 보존했다.

## 사용 조건 확인 상태

| 대상 | 현재 상태 | 미확정 사항 |
| --- | --- | --- |
| Z-Anatomy 폐 외형 | 파일 확보·추출·기초 검사 완료 | 각 오브젝트의 원저작물 대응, 공개·가공 배포 범위 |
| UMCG 폐·기도 모델 | 무료 비상업 후보로 유지, 다운로드 미확보 | 모델 페이지 403, API 요청은 202로 정상 모델·다운로드 응답을 반환하지 않음 |
| 유료 모델 | 제외 | 구매·유료 의뢰 진행하지 않음 |

UMCG는 다운로드가 확보된 모델처럼 기획에 포함하지 않는다. 필요하면 사용자가 공식 다운로드로 확보한 원본 파일을 받아 검사할 수 있다. Z-Anatomy의 혼합 출처 목록은 이전 [확보 기록](13-sample-acquisition.md)을 유지한다.

## 재현과 다음 판단

[검사·추출 스크립트](../research/scripts/inspect_z_anatomy.py)를 Blender에서 실행한 뒤 [미리보기 스크립트](../research/scripts/preview_z_lungs.py)를 실행한다. 상세 명령은 [재현 안내](../research/README.md)에 있다.

무료 모델 후보로는 Z-Anatomy 폐 외형을 다음 품질 개선 검토에 우선 사용한다. 남은 작업은 표면 보정 전후 비교, 경계·연결 원인 검사, 흉부의 다른 구조와 배치 정합성 확인이다.
