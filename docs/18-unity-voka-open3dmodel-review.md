# 추가 자료 검증: Unity 기록, VOKA, AnatomyTOOL

조사일: 2026-11-06. 사용자 제공 설명을 실제 원문과 대조했다. 목적은 우리 웹·앱에 사용할 무료 모델 후보와 경쟁 기능을 검토하는 것이다. 유료 모델은 후보에서 제외한다.

## 결론과 후보 분류

| 대상 | 이번 판단 | 확보 상태 |
| --- | --- | --- |
| Anatomy 3D Atlas의 Unity 사용 | 과거 iOS 실행 기록으로 확인 | 현재 Android 엔진·버전은 미확인 |
| VOKA | 무료 열람 및 설명 기능 비교 대상으로 유지 | 우리 제품에 넣을 무료 원본 파일·허락은 미확보 |
| AnatomyTOOL Open3DModel | 기존 무료 모델의 개선판 후보로 추가 | 배포 메타데이터 확인, 모델 파일은 미확보 |

무료 모델의 다음 확보 후보는 Open3DModel로 추가하되, 이미 확보한 Z-Anatomy 폐 외형을 대체한다고 결정하지 않는다. 부위·형상·재질을 실제 비교한 결과가 아직 없기 때문이다.

따라서 해당 iOS 버전의 Unity 사용 근거는 있다. 제작사의 최신 기술 명세나 현재 Android 바이너리 검사는 아니다. [원본 수집 기록](https://data.tweasel.org/data/requests/informed-consent,191765)

제작사는 영화·광고 분야 3D 애니메이션 경험과 해부학 모델 개발을 소개한다. 이 소개에는 Blender·Maya·3ds Max 등 제작 도구와 개별 모델 원출처가 명시되지 않는다. Z-Anatomy 사용이나 전량 자체 제작도 확인하지 못했다. [제작사 소개](https://catfishanimationstudio.com/en/home/)

우리 엔진 선택은 보류한다. 경쟁사의 Unity 사용은 참고 근거이며, 무료 모델의 표현 가능성·웹과 모바일 조작·로딩을 검증한 뒤 판단한다. 엔진이 같다는 사실만으로 동일한 시각 품질이 보장되지는 않는다.

## VOKA: 무료 열람과 모델 공급 구분

공식 제품 페이지의 1,000개 이상 모델 무료 접근 안내를 확인했다. 또한 단면 보기, 모델 위 그림·텍스트, 강조·포인터, 이미지 캡처와 링크 공유를 소개한다. 이는 공급자 설명이며 이번에 실제 조작한 것은 아니다. [공식 제품 안내](https://voka.io/product/)

App Store 이력의 **6.11.0, 2026-05-09**에는 라이브러리 무료 개방, 고급 기능 구독, 비로그인 제한이 적혀 있다. 따라서 사용자 제공 글의 ‘2026년 5월 변경’은 확인된다. 추가로 **6.8.0, 2025-11-21**에는 Unity 6 지원이 기재되어 있다. 이 기록을 VOKA 웹 카탈로그의 엔진 증거로 확대하지 않는다. [개발자 등록 버전 이력](https://apps.apple.com/us/app/voka-3d-anatomy-and-physiology/id1554827597)

웹 카탈로그는 로그인 후 모든 모델·기능 무료 이용이라고 안내한다. 모바일의 구독 설명과 범위가 같다고 단정하지 않으며, 실제 계정·플랫폼별 제공 범위는 미검증이다. [웹 카탈로그](https://catalog.voka.io/en)

사용자 제공 약관 링크는 **voka.io 웹사이트용**이며 앱·다른 하위 도메인은 별도 약관 대상이라고 명시한다. 이 웹사이트 약관은 모델 추출·외부 삽입을 별도 허락 대상으로 안내한다. [웹사이트 약관, 2026-09-24](https://voka.io/terms-of-use/)

카탈로그가 연결한 **앱 약관**도 확인했다. 개인 이용 권한과 모델·소스코드 권한을 구분하고 소유권 고지 제거를 제한한다. 업데이트 표기는 2023-12-27이다. 현재 페이지 간 갱신 시점이 다르므로 무료 열람 안내를 우리 제품의 재배포 허락으로 해석하지 않는다. [앱 약관, 12·19항](https://catalog.voka.io/en/terms-of-use)

따라서 VOKA는 경쟁 경험 비교 대상으로 유지한다. 우리 서비스에 넣을 무료 다운로드 자산이나 별도 허락은 확보하지 않았다. 유료 계약·구매는 추진하지 않는다.

## AnatomyTOOL Open3DModel: 개선판 후보 확인

AnatomyTOOL 자료가 연계된 edusources 상세 페이지에서 **척수·주변 구조 모델의 2026년 9월 버전**을 확인했다. 해부학 담당자와 3D 모델러가 기재되어 있고, BodyParts·Z-Anatomy 기반 개선 모델이며 CC BY-SA 조건으로 소개된다. ‘완전히 새로운 독립 인체 원본’으로 분류하지 않는다. [척수 모델 상세 메타데이터](https://edusources.nl/en/materials/oai:anatomytool.org:63977)

근육 부착 모델도 발견했다. 메타데이터의 게시일은 2026-07-04, 모델 버전은 2026년 3월이다. 게시일을 제작·개선 버전으로 혼동하지 않는다. [근육 부착 모델 메타데이터](https://edusources.nl/en/materials/oai:anatomytool.org:63973)

원본 [모델 목록](https://anatomytool.org/open3dmodel-learn), [제작·활용 안내](https://anatomytool.org/open3dmodel-create), [척수 원문](https://anatomytool.org/node/63977)은 이번 접속에서 읽지 못했다. 웹 도구는 타임아웃, 로컬 HTTPS 요청은 인증서 만료 검증 오류를 반환했다. edusources의 Download & links는 원본 페이지 연결이며 Blender·OBJ 파일 자체를 받은 것은 아니다.

확인 범위는 연계된 배포 메타데이터까지다. 정확한 라이선스 버전, 개별 메시의 예외 조건, 배포 파일 형식, 텍스처 포함 여부, 다운로드 가능 여부와 최종 품질은 미확정이다. CC BY-SA 표기가 출처 표시 없는 사용을 허용한다는 뜻도 아니므로 사용자 확인 예정 상태를 유지한다.

## 우리 기획에서 바뀌는 판단

1. **설명 기능만으로 차별화가 충분하다고 가정하지 않는다.** VOKA도 주석·포인터·캡처·공유를 소개한다. 우리 기획은 ‘기관 사이를 벌려 위치 관계를 설명하고 원상복원하기’가 더 쉽게 되는지, 한국어 설명 장면을 준비·재사용하기 쉬운지를 검증해야 한다.
2. **무료 후보 목록에 Open3DModel을 추가한다.** 원본 배포 경로가 확인되면 부위 하나를 확보해 기존 모델과 같은 조건으로 비교한다. 신규 후보의 존재를 샘플 확보 완료나 더 높은 품질의 증거로 취급하지 않는다.
3. **현재 무료 폐 샘플은 유지한다.** 다음 품질 검증에 바로 사용할 수 있는 것은 이미 확보한 Z-Anatomy 파일이다. Open3DModel의 흉부·폐 파일이 더 적합한지는 별도 확인한다.

이번 작업은 원문 대조와 문서 정리다. 신규 모델 다운로드, 앱 가입·설치·구매, 제작자에게 연락, 제품 개발은 하지 않았다.
