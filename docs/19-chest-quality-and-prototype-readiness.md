# 흉부 모델 품질 비교와 시제품 착수 기준

작성일: 2026-11-06. 연결 이슈: [#7](https://github.com/Yongyeon-Kim/anatomy-3d/issues/7).

## 판단

**내부 조작 시제품을 시작할 자산 후보를 준비했다.** 기본 형상에 부드러운 음영을 적용한 모델을 첫 기준으로 사용하고, 세분화 모델은 비교 후보로 유지한다. 완성 제품 수준의 질감, 의학 검수, 모바일 성능은 미완료다.

이번 단계의 결과는 ‘무료 모델로 시제품을 시작할 수 있음’이다. 경쟁 앱 수준의 최종 품질이나 공개 배포 가능성을 승인한 것은 아니다.

## 비교 조건

Z-Anatomy 고정 배포본의 원래 다각형 메시를 복사했다. 기존 OBJ는 이미 삼각형으로 변환되어 있어 세분화 기준으로 사용하지 않았다. 원본의 위치·방향·크기를 유지하고, 부모·제약·원본 렌더 설정을 가져오지 않은 별도 장면에서 검사했다.

Blender 3.6.23, Cycles CPU 24 samples, 640×640, Filmic/Medium High Contrast 조건이다. A/B/C 사이에는 카메라 2방향, 조명, 단색 재질이 같다. 실제 조직 질감이나 새로운 해부학 구조를 생성하지 않았다. 원본 파일의 자동 실행 코드는 끄고 원본 저장도 하지 않았다.

원본의 선화 합성 설정이 첫 출력에 남는 문제를 발견해 새 장면으로 재생성했다. 밝은 뼈의 하이라이트가 과하게 날아가는 것을 줄이기 위해 최종 비교에는 Filmic 색상 변환을 적용했다. 최종 이미지만 품질 판단에 사용한다.

## 폐 5개 엽의 비교 결과

| 구분 | A: 기본 면 음영 | B: 부드러운 음영 | C: 세분화 1단계 |
| --- | ---: | ---: | ---: |
| 삼각형 | 10,342 | 10,342 | 42,144 |
| 정확한 좌표 병합 후 경계 모서리 | 72 | 72 | 144 |
| 정확한 좌표 병합 후 비다양체 모서리 | 5 | 5 | 8 |
| 면적 1e-12 이하 삼각형 | 0 | 0 | 0 |
| 기본 메시와 좌표·면 해시 일치 | 기준 | 일치 | 불일치: 형상 변경 |

경계 모서리 수는 구멍 개수가 아니다. 세분화에서 모서리가 나뉘므로 단순 수량 증가를 결함 증가율로 해석하지 않는다. 어느 방식도 기존 연결 문제를 수리한 것은 아니다.

C의 평가 정점에서 A의 최근접 삼각형 표면까지 측정한 최대 거리는, 각 엽의 기본 경계상자 대각선 대비 최대 **0.6763%**다. 단방향 정점 거리이며 전체 표면의 최대 편차나 의학적 허용 오차가 아니다. 물리 단위 보정을 확인하지 않아 mm로 환산하지 않는다.

최종 비교 이미지에서 B는 A의 각진 면 음영을 줄였고, C는 윤곽과 엽 경계도 더 둥글게 만든다. B와 C 모두 조직 질감이 없는 단순 표면이며 일부 접합부·아래쪽의 음영과 형태는 추가 확인이 필요하다. C를 ‘더 정확한 폐’로 판단하지 않는다.

- 로컬 비교 이미지: `research/results/lungs-quality-comparison.png`.
- 세부 측정: [chest-preparation.json](../research/results/chest-preparation.json).
- **첫 선택 B:** 원래 형상을 유지하며 조작 검증을 시작한다. C는 시각 품질·형상 검토 후 채택 여부를 정한다.

각 객체의 원본 월드 행렬을 보존해 한 장면에 배치했다. 갈비뼈를 표시한 장면과 숨긴 장면을 같은 카메라로 확인했다. 서로 다른 배포본을 임의로 맞춰 합친 결과가 아니다. 좌표 공유와 시각 관찰은 확인했지만 구조 간 충돌·정확한 접촉 관계를 검증하지 않았다.

심장은 심방·심실 4개만 포함한 검토용 부분 묶음이다. 혈관·판막·신경 등이 모두 포함된 완전한 심장 모델로 표시하지 않는다. 기관지 나무도 이번 묶음에 없다. 기관에서 폐까지 연결된 호흡 경로 설명 자료로 승인하지 않는다.

로컬 이미지: `research/results/chest-context-comparison.png`. 갈비뼈가 많은 삼각형을 차지하므로 이후 성능 검증에서 우선 측정할 대상이다. 현재 수량만으로 휴대폰 실행 가능 여부를 판단하지 않는다.

## 시제품용 로컬 파일과 검증

`research/samples/chest-review/`에 다음 파일을 준비했다. 모두 원본 계보·가공 내용을 보관한 내부 후보이며 GitHub에는 올리지 않는다.

- `lungs-smooth.glb`: 5개 엽, 부드러운 음영. 가벼운 조작 검증용.
- `lungs-subdivision1.glb`: 5개 엽, 세분화 비교용.
- `chest-smooth.glb`: 흉부 58개 메시, 부드러운 음영.
- `PROVENANCE.txt`: 원본 커밋·해시·라이선스 기록 경로와 가공 내용.

GLB는 별도 라이브러리로 다시 읽고 객체 이름·노드 수, 객체별 삼각형 수, 유한한 위치·법선, 객체별 표면 경계상자와 파일 해시를 검사했다. glTF의 Y-up을 원본 Z-up으로 되돌려 표면 경계 오차 1e-6 원본 단위 미만을 기준으로 삼았으며, 3개 파일 모두 통과했다. 객체별 최대 오차는 약 1.80e-7이다. 이 검사는 렌더러에서의 재질 일치·실제 FPS를 보장하지 않는다. [검증 결과](../research/results/chest-export-validation.json)

흉골 몸통에는 삼각형이 참조하지 않는 정점 5개가 있어, 전체 정점 경계와 내보낸 표면 경계를 비교하면 불일치가 발생했다. 왼심방 2개·흉골자루 3개·좌우 여섯째 갈비뼈 각 10개도 미참조 정점이 있으나 이번 표면 경계 불일치 원인은 흉골 몸통이었다. 원본 정점은 보존하고 검사에는 삼각형이 실제 사용하는 표면 경계를 적용한다. 전체 경계·미참조 정점 수는 측정 파일에 별도로 남긴다. 허용 오차를 늘려 통과시키지 않는다.

[시제품 묶음 명세](../research/results/chest-prototype-manifest.json)는 왼쪽 폐·오른쪽 폐·심방/심실 묶음·갈비뼈/늑연골/흉골·횡격막·기관의 **6개 선택 묶음**에 모든 메시를 중복 없이 배정한다. 이 묶음은 첫 조작 범위이며 정식 출시의 해부학 분류를 확정한 것은 아니다.

성능 목표 초안은 준비된 장면을 30초 회전할 때 중앙값 프레임 시간 33.3ms 이하, 95백분위 50ms 이하이다. 공식 지원 최소 사양이 아니며 첫 실제 기기 측정 후 조정한다. 로딩 시간은 파일 전송과 파싱을 구분해 측정하고 조건 없는 단일 수치를 목표로 삼지 않는다.

첫 시제품에서 절단면 생성·조직 변형·생리 시뮬레이션은 다루지 않는다. 열린 메시와 구조 간 연결 검토가 선행되어야 한다. 로그인·결제·퀴즈·전신 구현도 이번 조작 검증 범위에 넣지 않는다.

## 착수와 공개 기준

- **내부 조작 시제품:** 위 후보를 사용해 진행할 수 있다. 구조 누락·경계 문제는 알려진 제한으로 기록한다.
- **시각 품질 확정:** 미완료. 단색 표면을 개선하고 경계·형태를 검토한 뒤 설명용 품질을 판단한다.
- **의료 설명 자료 공개:** 미완료. 설명에 필요한 구조 완성도와 용어·위치의 전문가 검토가 필요하다.
- **웹 공개·앱 등록:** 미완료. 사용 자산별 출처와 이용 조건을 확인하고 실제 기기 검증·출시 준비를 완료해야 한다.

이번 이슈의 완료는 자산 비교·후보 준비·착수 기준 작성 완료를 의미한다. 실제 조작 시제품 구현은 다음 작업이다. 유료 모델 제외 조건과 웹·앱 출시 목표를 유지한다.
