# 기존 서비스와 해부학 자료 조사

조사 기준일은 2026-11-06이다. 서비스 기능은 공식 공개 설명을 기준으로 확인했으며, 유료 제품의 직접 조작이나 원본 모델 품질 검사는 진행하지 않았다. 아래 평가는 기획 의사결정을 위한 비교다.

후속 실제 확보·검사 결과는 [확보 기록](13-sample-acquisition.md)과 [품질 검사](14-sample-quality-review.md)를 따른다. 아래 내용은 초기 후보 조사이며, 이후 Z-Anatomy의 혼합 출처 조건과 BodyParts3D의 과거 헤더·현재 고지 차이를 확인했다.

이후 사용자가 유료 모델을 제외했으므로 아래 상용 구매·플랫폼 비교는 과거 조사 기록이다. 현재 모델 선정은 [무료 모델 재검토](16-free-model-review.md)를 따르며 무료·비상업 후보만 포함한다.

## 기존 서비스

| 대상 | 공식 자료로 확인한 특징 | 참고할 경험 | 추가 확인 사항 |
| --- | --- | --- | --- |
| Complete Anatomy | 남녀 해부 모델, 구조 탐색, 퀴즈·교육 콘텐츠 | 상세 탐색과 학습 과정 연결 | 분리 조작의 실제 흐름, 초보자 난이도 |
| Visible Body Suite | 해부 모델, 근육 작용, 웹·모바일 접근, 사용자 장면 저장·공유 | 기기 간 학습과 근육 콘텐츠 구성 | 작은 화면에서 선택·라벨 처리 |
| BioDigital | 개발자 도구를 통한 모델 연동, 학교·기업 플랜 관련 이용 요건 | 기존 플랫폼을 사용하는 공급 방식 | 분리 변환의 자유도, 계약·오프라인 조건 |
| MEDIP Box | 3D 해부학, 실제 해부 사진, 영상·단면 비교, 한국어 지원 | 국내 교육 맥락과 자료 연결 | 개인 웹·앱 이용 범위와 기관용 제품의 차이 |

출처: [Complete Anatomy](https://www.elsevier.com/products/complete-anatomy), [Visible Body](https://www.visiblebody.com/practitioners), [BioDigital 개발자 이용 요건](https://support.biodigital.com/hc/en-us/articles/22012525162391-Remove-a-developer-from-my-team), [MEDIP Box](https://renewal.medicalip.net/medipbox/).

‘한국어 지원’이나 ‘3D 탐색’ 자체를 독점적인 차별점으로 잡기는 어렵다. 짧은 학습 과정에서 조작을 익히고 정상 배치까지 이해하는 경험에 가설을 두는 것이 타당하다. 이는 경쟁 제품의 사용성 열위를 확인한 결론은 아니다.

## 원본 자료와 모델 후보

### BodyParts3D

공식 아카이브는 성인 남성 전신의 해부 구조를 3D 데이터로 제공한다고 설명한다. 현재 이용 허락 페이지는 **CC BY 4.0**이며 마지막 갱신일을 2025-02-27로 표시한다. 과거 자료에 다른 라이선스가 적혀 있을 수 있으므로 실제 사용할 배포본과 공식 안내를 함께 보관한다. [데이터 설명](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/desc.html), [이용 허락](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)

**제안:** 첫 모델 후보로 우선 검토한다. 구조별 선택과 분리 보기에 필요한 오브젝트 구분, 상대 좌표, 이름 연결이 갖춰졌는지를 샘플로 확인한다. 공개된 데이터라는 사실만으로 교육 품질·모바일 성능·표면 질감이 충족된다고 보지 않는다. 여성·소아·개인차를 모두 대표하는 모델로 소개하지 않는다.

### Z-Anatomy

프로젝트 후원기관 SPI는 Z-Anatomy를 다국어 용어와 교육 도구를 포함하는 협업형 3D 해부학 아틀라스로 소개하며 **CC BY-SA 4.0**을 표시한다. [SPI 프로젝트 소개](https://www.spi-inc.org/projects/z-anatomy/)

**제안:** 해부학 구조 구성과 편집 가능한 자산 후보로 비교한다. 프로젝트 소개의 라이선스를 모든 파일에 일괄 적용하지 않고, 채택할 모델·코드·텍스트별 조건을 확인한다. 상업 이용과 수정은 CC BY-SA에서 허용하지만, 배포하는 수정 자료에는 동일조건변경허락 요건이 있다. 이를 곧바로 ‘앱 코드 전체 공개 의무’라고 단정하지 않는다. [CC BY-SA 4.0 공식 요약](https://creativecommons.org/licenses/by-sa/4.0/)

### BioDigital 연동

자체 모델 제작 대신 기존 플랫폼을 연동하는 선택지다. 공식 도움말은 개발자 도구 이용에 활성 School 또는 Business 구독과 등록된 도메인·앱 식별자 등이 필요하다고 설명한다. [공식 도움말](https://support.biodigital.com/hc/en-us/articles/22012525162391-Remove-a-developer-from-my-team)

**제안:** 콘텐츠 확보 시간을 줄일 가능성과 커스텀 조작 제약을 함께 비교한다. 기관별 이동, 원위치 복원, 독자 UI, 오프라인 저장, 사용자 수 과금, 계약 종료 시 처리를 공급사에 확인할 목록으로 남긴다. 공개 개발자 소개 일부는 현재 열람 시 계정 선택 화면으로 보여 세부 API 동작을 확정하지 않았다.

### Visible Human Project

NLM은 남성과 여성 시신에서 얻은 냉동 절단면·CT·MRI 영상 자료를 public domain 자료로 안내한다. **장기별로 완성된 실시간 3D 모델 묶음과는 다른 종류의 자료**다. [NLM 공식 안내](https://www.nlm.nih.gov/research/visible/visible_human.html)

**제안:** 초기 회전·분리용 모델보다 후속 단면 학습 후보에 둔다. 3D 구조로 활용하려면 영역 구분, 표면 구성, 영상과 모델의 대응 확인 등 추가 작업이 필요하다. 파생 가공본을 다른 곳에서 받는다면 그 배포본 조건도 따로 확인한다.

### 교재와 용어 자료

- OpenStax는 학습 순서와 기초 개념을 확인하는 참고 자료다. 현재 확인한 Anatomy and Physiology 2e 페이지는 **CC BY-NC-SA**를 표시하므로 무료 열람을 근거로 상업 서비스에 본문·그림·문제를 복제하지 않는다. 제품용 설명과 문제는 별도 집필·검수하거나 필요한 이용 허락을 확보한다. [현재 페이지의 이용 조건](https://openstax.org/books/anatomy-and-physiology-2e/pages/1-2-structural-organization-of-the-human-body)
- TA2와 TA2Viewer는 영문·라틴어 표준 용어 연결 후보다. 한국어 표준 용어집의 판본과 이용 조건은 추가 확인 항목이다. [IFAA 안내](https://ifaa.net/2022/08/12/report-of-the-federative-international-programme-on-anatomical-terminologies-fipat/)

## 자료 확보 방식 비교

아래 비용 평가는 견적이 아니라 비용이 발생하는 위치에 대한 판단이다.

| 방식 | 유리한 점 | 주요 비용·제약 | 현 단계 판단 |
| --- | --- | --- | --- |
| 공개 모델을 검수·가공 | 분리 조작과 화면 구성의 자율성 | 정리, 모델 보수, 명칭 연결, 검수 | 첫 검토 후보 |
| 상용 플랫폼 연동 | 콘텐츠·뷰어를 함께 확보할 가능성 | 이용료, 계약 범위, 조작 제약 | 비교 견적 후보 |
| 상용 모델 구매 | 특정 부위나 표현 보완 가능 | 앱 배포·추출·수정 권리 확인 | 부족한 부위 보완 후보 |
| 전용 모델 제작 | 목적에 맞춘 형태와 분할 | 제작 기간, 의학 검수, 유지보수 | 핵심 부위 한정 후 검토 |

## 모델 선정 기준

1. **개별 선택:** 학습할 장기·근육이 별도 구조로 나뉘는가.
2. **정상 배치:** 같은 기준 좌표에서 구조들이 올바르게 맞물리는가.
3. **이름 연결:** 구조 식별자와 용어를 연결할 수 있는가.
4. **분리 적합성:** 연결 구조가 잘못 늘어나거나 분리되지 않는가.
5. **교육 정확성:** 형태·좌우·포함 범위·생략 항목을 검토할 수 있는가.
6. **기기 적합성:** 모바일에서 필요한 세부 형태를 유지하며 표시할 수 있는가.
7. **활용 권리:** 수정, 웹·앱 배포, 오프라인 저장, 출처 표시 조건이 명확한가.

실사 질감의 품질보다 1~5가 먼저다. 형태가 하나로 합쳐진 예쁜 모델은 장기별 간격 조절에 적합하지 않을 수 있다.

## 자산 기록 양식

실제 자료를 확보할 때 아래 항목을 기록한다. 현재는 후보 조사 단계이며 다운로드한 자산은 없다.

| 항목 | 기록 내용 |
| --- | --- |
| 자료명·버전 | 배포 이름, 버전, 확보일 |
| 원본 | 제공기관, 원본 URL, 원본 파일 식별 정보 |
| 범위 | 부위, 성별·연령 범위, 포함·누락 구조 |
| 이용 조건 | 라이선스, 고지 문구, 수정·재배포 조건 |
| 가공 이력 | 형태 수정, 경량화, 이름 연결, 좌표 변경 |
| 검수 | 검수자, 날짜, 발견 오류, 공개 가능 상태 |
