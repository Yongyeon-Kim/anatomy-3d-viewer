# 3D 조작과 분리 보기 기획

## 핵심 구분

확대·축소는 화면에 보이는 크기를 바꾸고, 분리 보기는 구조물 사이의 간격을 바꾼다. 사용자가 요청한 밀고 당기는 경험은 **분리 슬라이더**와 **선택 구조물 이동 모드**로 제안한다. 아래 내용은 개발 명세에 앞선 제품 행동 설계다.

| 기능 | 무엇이 바뀌는가 | 학습 목적 |
| --- | --- | --- |
| 회전 | 관찰 방향 | 앞에서 가려진 부분 보기 |
| 확대·축소 | 관찰 배율 | 작은 구조 확인 |
| 화면 이동 | 화면 내 모델 위치 | 관심 부위를 중앙에 놓기 |
| 숨김·투명도 | 구조물의 보이는 정도 | 깊은 구조 확인 |
| 단독 보기 | 선택한 구조 중심의 표시 | 모양과 이름 집중 학습 |
| 분리 보기 | 구조물의 표시 위치와 간격 | 겹치는 구조 구분 |
| 원위치 복귀 | 원래의 해부학적 배치 | 실제 위치 관계 재확인 |

## 간격 조절의 단계

### 1단계 묶음 분리

‘정상 배치 0 → 넓게 보기 100’ 슬라이더를 사용한다. 숫자는 **학습용 분리 정도**이며 실제 거리나 밀리미터가 아니다. 부위별로 검토한 이동 방향과 범위를 적용한다. 장기 크기나 형태를 늘리는 조작으로 표현하지 않는다.

0에서는 원래 위치가 복원되고, 값을 올리면 정해진 구조물 그룹이 벌어진다. 슬라이더를 줄이면 같은 경로로 돌아온다. 최대 분리 범위는 구조물끼리 겹치거나 화면 밖으로 벗어나지 않는지를 보며 결정한다.

### 2단계 선택 구조물 이동

이 단계는 후속 기능으로 둔다. 첫 공개에서는 묶음 분리의 이해도와 복원 동작을 먼저 검증한다.

‘구조물 이동’ 모드를 켠 뒤 선택한 장기 또는 그룹을 가이드 방향으로 당겨 본다. 기본 회전 조작과 충돌하지 않게 모드를 명시한다. 초기에는 자유로운 3축 이동보다 제한된 경로를 우선 검토한다.

연결된 관·혈관을 어디까지 함께 움직일지는 콘텐츠 단위로 정한다. 임의로 늘어난 혈관을 실제 상태처럼 표시하지 않는다. 연결 관계를 보여 줄 필요가 있으면 설명용 점선임을 구분하고 원위치 화면에서 실제 연결을 확인한다.

## 오해를 줄이는 화면 규칙

- 분리 중에는 ‘학습용 분리 상태’ 표시를 유지한다.
- 몸통 윤곽 또는 원래 자리의 옅은 표시를 남긴다.
- ‘배치 복원’은 구조 위치를, ‘화면 초기화’는 관찰 방향·배율까지 복원하도록 구분한다.
- 위치 관계 퀴즈를 시작하면 원위치로 되돌린다.
- 구조물 이동 범위를 넘겨 당겨도 크기 변화나 비현실적인 관통으로 표현하지 않는다.
- 분리 효과를 실제 수술이나 조직의 물성 재현으로 설명하지 않는다.

## 2차 검토에서 추가한 조작 원칙

- **분리는 선택한 부위에 적용:** 전신을 한 번에 벌리지 않는다. 적용 범위를 슬라이더 옆에 표시한다.
- **장기와 근육을 구분:** 장기는 검수된 그룹을 벌리고, 근육은 얕은 층에서 깊은 층으로 숨김·투명도를 조절하는 방식을 우선한다. 전체 구조를 한 방향으로 퍼뜨리는 규칙을 공통 적용하지 않는다.
- **회전 기준 선택:** 전신 회전과 선택 구조 중심 회전을 구분한다. 선택 구조가 바뀌어도 화면이 갑자기 멀리 이동하지 않게 한다.
- **관계 보기:** 선택 구조의 주변 구조를 함께 강조한다. 정상 위치 관계는 원위치에서만 설명하고, 분리 중 관계 보기를 누르면 복원을 안내한다.
- **한 단계 되돌리기:** 숨김·분리·투명도 변경을 취소할 수 있다. 전체 초기화만 제공하면 사용자가 만든 장면이 사라진다.
- **원위치 미리보기:** 버튼을 누르는 동안 정상 배치를 보여 주고 놓으면 분리 상태로 돌아간다. 터치·키보드에서는 고정 전환 버튼도 제공한다.
- **검색 결과 처리:** 숨겨진 장기를 검색하면 해당 구조를 표시하고 위치를 안내한다. 현재 장면으로 되돌리는 기능을 제공한다.
- **퀴즈와 정답 화면 구분:** 문제 중에는 정답을 드러내는 이름 라벨·검색 안내를 제한하고, 회전·확대는 허용한다. 답안 제출 후 설명과 관계 보기를 제공한다.

‘단면 보기’는 내부 데이터 확보 후, ‘근육 움직임’은 관절·부착 검수 후 도입한다. 층별 보기가 실제 절단이나 근육 수축을 재현한다고 표현하지 않는다.

## PC와 터치 조작 제안

| 행동 | PC | 휴대전화·태블릿 |
| --- | --- | --- |
| 회전 | 기본 드래그 | 한 손가락 드래그 |
| 확대·축소 | 휠 또는 화면 버튼 | 두 손가락 핀치 또는 버튼 |
| 화면 이동 | 이동 도구 또는 보조 버튼 드래그 | 이동 모드 또는 두 손가락 이동 |
| 구조 선택 | 클릭 | 탭, 겹치면 후보 목록 |
| 간격 조절 | 슬라이더 드래그 | 큰 슬라이더 핸들 조작 |
| 선택 장기 당기기 | 구조물 이동 모드에서 드래그 | 구조물 이동 모드에서 드래그 |
| 원위치 복귀 | 고정 버튼 | 손이 닿는 위치의 고정 버튼 |

핀치를 확대와 간격 조절에 동시에 배정하지 않는다. 키보드·화면 버튼으로도 회전과 분리 정도를 조절하고, 애니메이션 감소 옵션을 제공하는 안을 포함한다.

## 화면 구성 초안

| 영역 | PC 웹 | 모바일 |
| --- | --- | --- |
| 탐색 | 왼쪽에 부위·계통·검색 | 상단 검색과 펼침 메뉴 |
| 3D 화면 | 중앙의 가장 큰 영역 | 설명 패널을 접으면 화면 중심 |
| 설명 | 오른쪽 카드 | 아래에서 여닫는 카드 |
| 조작 | 모델 아래 도구 모음 | 하단의 핵심 도구 |
| 분리·복원 | 슬라이더와 복원 버튼 상시 접근 | 전용 모드에서 큰 슬라이더 |

모든 이름을 동시에 표시하기보다 선택한 구조와 관련 구조 중심으로 라벨을 제공한다. 색만으로 구분하지 않고 이름과 선택 테두리를 함께 사용한다.

## 첫 학습 시나리오

1. ‘가슴 속 구조 찾기’를 열면 정상 배치와 방향 표시가 보인다.
2. 좌우로 돌려 관찰하고 흉곽의 투명도를 조절한다.
3. 폐와 심장을 각각 선택해 짧은 설명을 본다.
4. 분리 정도를 올려 겹쳐 보이던 구조를 확인한다.
5. ‘배치 복원’을 눌러 정상 위치를 다시 관찰한다.
6. 이름 라벨을 가린 뒤 지정된 구조를 선택한다.
7. 위치 관계 문제를 풀고 설명 화면으로 돌아간다.

문제의 정확한 문구와 정답은 해부학 검수 후 확정한다.

## ‘실제처럼 보임’의 범위

초기에는 형태·비율·위치가 이해되는 일관된 표현을 우선한다. 실사 질감, 단면 내부, 혈류·호흡 애니메이션, 조직 변형은 각각 다른 자료와 검수가 필요하다.

특히 표면만 있는 3D 모델을 잘라 보여 준다고 내부 해부 구조가 생기지는 않는다. 단면 학습을 넣으려면 내부 구조 데이터 또는 대응 영상이 필요하다. 단순히 모델 일부를 숨긴 기능과 실제 단면 콘텐츠를 구분한다.

## 기획 검증 기준 제안

- 처음 보는 사용자가 확대와 간격 조절을 구분하는가.
- 분리 후 스스로 정상 배치로 복귀하는가.
- 화면을 회전해도 인체 기준 좌우를 혼동하지 않는가.
- 작은 구조를 손가락에 가리지 않고 고를 수 있는가.
- 분리 상태를 정상 인체 배치라고 오해하지 않는가.
- 조작 설명 없이 구조 찾기 과정을 완료할 수 있는가.

모델 성능, 입력 지연, 충돌 여부는 이후 실제 모델을 사용하는 검증 단계에서 확인한다. 현재는 작동 결과가 아니라 검증할 항목이다.
