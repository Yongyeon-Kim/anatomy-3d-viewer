# 인체 탐색과 시각적 설명 용도

사용자 확인일: 2026-11-06. **이 제품은 공부에 한정되지 않는다. 의사나 일반인이 다른 사람에게 인체를 시각적으로 보여 주는 자료와 설명 도구로도 사용한다.** 웹 공개와 앱 등록이라는 최종 목표는 유지한다.

## 세 가지 사용 흐름

| 흐름 | 사용자 목적 | 주요 기능 | 완료되는 순간 |
| --- | --- | --- | --- |
| 자유 탐색 | 궁금한 부위를 찾고 관찰 | 검색, 회전, 선택, 숨김, 분리·복원 | 원하는 구조와 위치를 확인 |
| 학습 | 이해하고 기억하며 복습 | 안내 과정, 이름·관계 문제, 오답·진도 | 학습 목표를 확인하고 복습할 항목 저장 |
| 설명·발표 | 상대방에게 인체 구조를 보여 주며 설명 | 강조, 큰 라벨, 단순 화면, 장면 순서, 포인터 | 상대방이 설명한 구조·관계를 이해 |

3D 모델·용어·검색은 공통으로 사용한다. 설명 모드에서는 퀴즈·점수·복습 알림을 앞에 두지 않는다. ‘학생용·의사용’ 계정 선택을 먼저 요구하기보다 지금 하려는 행동으로 진입한다.

## 대표 활용 시나리오

### 의사가 환자에게 설명

관심 부위를 검색 → 주변 구조를 정리 → 특정 구조를 강조 → 회전하거나 벌려 가려진 부분 표시 → 정상 배치 복원 → 설명을 마친다. 설명자는 정확한 용어를 사용하고, 화면에는 쉬운 이름을 함께 표시할 수 있다.

현재 확정된 범위는 일반 인체 모델을 이용한 설명이다. 환자 개인 영상·진단 정보를 연결하거나 질환·시술을 보여 주는 기능은 별도 콘텐츠 요구로 정한다. 일반 모델이 특정 환자의 실제 상태를 나타낸다고 표현하지 않는다.

### 강의와 발표

설명할 장면을 순서대로 저장 → 전체 화면으로 표시 → 다음·이전 장면으로 이동 → 각 장면에서 자유롭게 회전 → 저장된 시점으로 복귀한다. 슬라이드나 배포 자료로 활용할 수 있는 출력 형식도 검토한다.

### 일반인이 보여 주기

전문 용어를 몰라도 부위와 쉬운 이름으로 찾기 → 라벨과 짧은 설명 보기 → 상대방에게 화면을 보여 주거나 설명 장면을 전달한다. 학습 기록이나 문제 풀이 없이도 사용할 수 있다.

시각 자료로 재사용하는 용도에서는 화면에서 볼 권리와 이미지·영상·인쇄물로 배포할 권리를 구분한다. 현재 모델 후보가 모든 출력 권한을 충족한다고 확정하지 않는다.

## 기존 기획에서 달라지는 점

- ‘관찰 → 퀴즈’만이 아니라 ‘검색 → 장면 정리 → 강조 → 설명 → 저장’ 흐름을 추가한다.
- 장면 저장을 학습 북마크와 설명 준비에 공통 활용한다.
- 장기 분리 중에는 학습용 배치 표시를 설명 모드에서도 유지한다.
- 분리 상태의 캡처·공유에도 원래 배치와 다르다는 표시가 남도록 설계한다.
- 발표 중 회전한 뒤 저장 시점으로 돌아갈 수 있게 한다. 자유 회전이 발표 순서를 망가뜨리지 않아야 한다.
- 사용자마다 진도·점수를 가질 필요는 없다. 설명만 하는 사용자에게도 완결된 경험을 제공한다.

## 2차 검증에 추가할 과제

| 검증 대상 | 과제 | 확인할 점 |
| --- | --- | --- |
| 의사 등 설명자 | 한 부위를 찾아 2분 이내 구조 관계 설명 | 검색과 화면 정리에 시간을 과하게 쓰지 않는가 |
| 설명을 듣는 일반인 | 설명 후 같은 구조를 화면에서 가리키기 | 라벨·분리·회전이 이해를 돕는가 |
| 발표자 | 저장된 장면 3개로 짧은 설명 | 시점과 강조 상태가 복원되는가 |
| 일반 사용자 | 용어를 모르는 부위를 찾아 보여 주기 | 쉬운 이름·부위 탐색으로 도달하는가 |
| 공유 수신자 | 전달받은 장면 또는 이미지 열기 | 출처·표시 상태를 이해하고 내용 확인이 가능한가 |

2분·3개 장면은 사용성 과제의 제안 조건이며 성능 또는 교육 효과의 확정 기준이 아니다. 학습자 인터뷰와 별도로 설명자·청자 검증을 계획한다.

## 출시 기준에 추가할 내용

웹과 앱의 첫 공개에서 학습 과정뿐 아니라 하나의 설명 시나리오를 끝까지 수행할 수 있어야 한다. 실제 제공 범위에 맞춰 소개 문구·스크린샷·스토어 정보를 작성한다. 발표·출력·공유 기능은 모델 라이선스와 동작을 검증한 범위만 홍보한다.
