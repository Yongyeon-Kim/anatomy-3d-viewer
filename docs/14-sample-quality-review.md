# 흉부 샘플 구조와 품질 검사 결과

검사일: 2026-11-06. 연결 이슈: [#5](https://github.com/Yongyeon-Kim/anatomy-3d/issues/5). **BodyParts3D PART-OF OBJ 99는 그룹 선택·분리의 기술 검토용으로 유지하되, 현재 조합을 환자 설명용 완성 모델로 채택하지 않는다.** 폐 외형, 횡격막 연결, 질감·모델 무게의 보완이 필요하다.

## 검사 범위

공식 구조 이름표의 FMA ID에서 구성 관계표의 요소 파일 ID로 내려가 10개 그룹을 구성했다. 파일 자동 수리는 하지 않았다. 입력 인덱스, 좌표 유한성, 경계·중복·퇴화면, 연결 성분과 변환 복귀를 점검하고 세 방향 및 단독 장기 미리보기를 눈으로 확인했다.

[그룹·측정 결과](../research/results/bodyparts-summary.json), [개별 파일 결과](../research/results/bodyparts-files.csv), [검사 스크립트](../research/scripts/audit_bodyparts.py)가 근거다. 의학적 정확성·충돌·자기 교차·실기기 성능 검사는 아니다.

C03은 전신 척추가 아니라 이번 장면에 필요한 흉추 구간으로 좁혔다. C01 몸통 윤곽은 아직 확보·검증하지 않았다. 매핑되는 파일의 누락은 0개이고, 이번 10개 그룹 사이의 동일 파일 중복도 0개다. 다른 전체 인체 그룹에도 중복이 없다는 뜻은 아니다.

각 파일은 개별 좌표를 가지므로 따로 표시하고 이동할 수 있다. 장기 선택은 한 파일이 아니라 위 요소 목록을 묶는 방식이 필요하다. 세부 요소를 함께 노출할 때 상위 그룹과 하위 요소가 이중 선택되지 않게 해야 한다.

## 시각 검사

로컬 `research/results/chest-preview.png`와 `isolated-organs.png`를 생성하여 확인했다. 원본 좌표와 삼각형을 유지하고, 그룹별 임시 색·주변 구조 투명도를 적용했다. 단독 장기는 불투명하게 표시해 투명도 때문에 외형이 사라진 것인지도 구분했다.

- 흉곽·척추·심장 등의 상대 배치를 한 장면에서 볼 수 있다. 각도에 따라 가리는 구조가 달라진다.
- 좌우 폐 그룹은 이번 매핑으로 조합했을 때 가지 구조 위주로 표시된다. 불투명 단독 보기에서도 설명용의 연속적인 폐 외형을 확인하지 못했다.
- 오른쪽 폐 그룹에는 주된 덩어리와 떨어져 보이는 작은 부분이 있다. 요소 매핑·포함 범위 또는 형상을 전문가와 확인해야 한다.
- 단색 미리보기이므로 미세한 표면 품질과 실제 조직 색을 평가하는 데 한계가 있다.

이 결과는 이번 PART-OF 배포본·매핑·렌더링에 한정된다. BodyParts3D 전체에 폐 외형이 없다는 결론이 아니다. 추가 배포본이나 다른 자료에서 외형을 확보할 여지는 남아 있다.

## IS-A 추가 비교

IS-A와 PART-OF는 이름이 같은 파일 1,258개를 공유하지만 바이트 해시는 모두 달랐다. 이 사실만으로 형상이 다르다고 판단하지 않았다. FJ2417·FJ3131·FJ2041 세 파일을 파싱해 비교한 결과 정점과 면 배열은 각각 동일했다. [표본 결과](../research/results/isa-spot-check.json)

IS-A 구성표에는 이번에 조회한 심장·좌우 폐의 동일 FMA ID 항목이 없어 PART-OF 그룹 구성을 그대로 대체하지 못했다. IS-A 전체 형상과 외형 보완 가능성은 검사하지 않았다.

## 분리와 복원 실험

각 그룹에 임의의 X축 이동을 0·25·50·100% 적용한 뒤 반대로 되돌렸다. 최대 좌표 오차는 약 `1.42e-14` 원본 좌표 단위였다. 원본 위치와 변환을 따로 보관하면 수치적으로 복원할 수 있음을 확인했다.

이 실험은 해부학적으로 자연스러운 분리 방향, 연결 혈관 처리, 구조 간 충돌, 사용자 조작감 검증이 아니다. 실제 UI나 물리 시뮬레이션을 만들지 않았다. 초기에는 가리는 구조를 숨기거나 투명하게 하는 관찰 방식부터 사용할 수 있다.

| 판단 | 대상 | 다음에 필요한 것 |
| --- | --- | --- |

| 보완 필요 | 좌우 폐 외형과 몸통 윤곽 | 적합한 외형 자료 확보·이름 매핑 |
| 가공·검수 필요 | 횡격막 비다양체 연결 | 수리 전후 형태 비교와 전문가 확인 |
| 최적화 검토 필요 | 432개 파일·54.7만 삼각형 | 그룹화·단계별 로딩·실기기 측정 |
| 미검증 | 해부학 정확성·한국어 표기·분리 경로 | 전문가 검수 |

현재 가장 먼저 해결할 것은 화면 개발보다 **설명에 사용할 장기 외형의 품질**이다. 차기에는 폐·몸통 외형 보완 후보와 Z-Anatomy 흉부 객체의 출처를 확인한 뒤, 비교할 수 있는 동일 시점의 모델 미리보기를 만드는 것이 타당하다.

이슈 #5의 완료는 파일 검사와 적합성 판단의 완료다. 제품용 모델 승인이나 의학 검수 완료가 아니다.
