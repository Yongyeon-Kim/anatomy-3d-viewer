# 시각적 품질과 출처 표시 방향

사용자 선호 확인일: 2026-11-06. 사용자는 출처 표시가 드러나지 않는 화면과 최대한 좋은 품질을 원하며, **유료 모델은 제외**한다고 명시했다. 무료 공개·비상업 이용 모델 안에서 품질과 화면 완성도를 우선한다. 유료 모델 구매와 유료 제작 의뢰는 후보에서 제외한다.

## 화면과 권리 조건

메인 3D 화면과 설명·발표 화면에는 출처 문구를 상시 겹쳐 표시하지 않는 방향을 우선 검토한다. 다만 기존 모델의 필수 출처 고지를 삭제하는 방식으로 구현하지 않는다.

CC 자료는 매체와 상황에 맞는 합리적인 방식으로 출처를 제공해야 한다. ‘정보 → 자료 출처 및 라이선스’처럼 접근 가능한 별도 화면을 사용하는 안을 검토하되, 자료별 요구를 확인한다. 이미지·영상으로 내보내면 그 결과물의 배포 상황에 맞게 고지 방법을 다시 정한다. 앱 정보 화면만으로 모든 출력물의 조건까지 충족한다고 가정하지 않는다. [CC 출처 표시 지침](https://wiki.creativecommons.org/wiki/Recommended_practices_for_attribution)

## 모델 확보 우선순위

| 후보 | 판단 기준 |
| --- | --- |
| 무료 공개 모델 | 품질·장기별 분할·웹·앱 배포·출력 조건 확인 |
| 무료 비상업 모델 | 비상업 사용 범위·가공·재배포·출처 표시 조건 확인 |
| 확보한 무료 모델 가공 | 폐 외형·연결·질감을 보완할 수 있는지 검토, 파생 조건 유지 |

무료라는 사실만으로 출처 표시 면제나 앱 재배포 허용을 가정하지 않는다. 이번에 검사한 모델을 최종 시각 품질의 기준으로 삼지 않는다. 비용이 필요한 후보가 나오면 구매하지 않고 제외한다.

## 품질 평가 항목

- 폐·심장·몸통의 외형과 비율이 설명에 적합한가.
- 장기별 선택·숨김·분리·복원이 가능한가.
- 확대해도 표면과 연결 부위가 자연스러운가.
- 피부·장기·혈관의 색과 질감이 일관되는가.
- 인체 구조와 표시 이름을 전문가가 검토할 수 있는가.
- 고품질 원본에서 모바일용으로 줄여도 설명에 필요한 형태를 유지하는가.

사진처럼 보이는 정도와 의학적 정확성은 따로 평가한다. 후보는 같은 시점·조명·확대 수준에서 비교한다. 모델을 구매하거나 기존 고지를 제거하는 작업은 이번 선호 기록에 포함하지 않는다.
