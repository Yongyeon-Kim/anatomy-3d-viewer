# 첫 체험판 콘텐츠 범위

작성일: 2026-11-06. 연결 이슈: [#1](https://github.com/Yongyeon-Kim/anatomy-3d/issues/1). 이 문서는 작업용 콘텐츠 범위를 구체화한 기획안이다. 사용자가 확정한 것은 탐색·학습·설명 용도와 웹·앱 출시 목표이며, 아래 구조 목록은 모델 확인과 전문가 검토에 따라 조정한다.

## 이번 범위 결정

흉부·복부를 첫 묶음으로 두되, 흉부 장면부터 구성 가능성을 확인한다. 같은 구조 목록을 자유 탐색, 학습 과정, 설명 장면에서 공유한다. 학습 전용 모델과 설명 전용 모델을 따로 만들지 않는다.

첫 체험판의 목적은 상세 의학 지식을 완성하는 것이 아니라 다음 세 흐름을 검토하는 것이다.

- 찾고 싶은 부위를 선택하고 앞·옆·뒤에서 관찰한다.
- 장기를 찾는 문제를 풀고 설명 화면으로 돌아간다.
- 관심 구조를 강조해 상대방에게 보여 주고 준비한 장면을 다시 연다.

## 구조 목록 초안

아래 ID는 기획 문서에서 사용하는 임시 식별자다. 실제 모델의 ID나 공인 해부학 코드를 뜻하지 않는다. 좌우는 인체 기준이다. ‘표시 단위’는 렌더링 파일 수가 아니라 사용자가 선택할 학습·설명 단위다.

총 20개 표시 단위의 후보이며, 4개는 주변 맥락, 16개는 주요 선택 구조다. 실제 모델 오브젝트 수와 다르다. 한국어 대표 표기와 영문 대응은 전문가 검토 후 확정한다.

초기 혈관·세부 신경·내부 심장 구조·장 세부 구획·골반 장기는 제외한다. 이는 의학적 중요도 판단이 아니라 첫 조작 검토의 범위 제한이다. 연결된 구조를 설명하려면 해당 구조를 추가한 뒤 그 설명을 공개한다.

## 모델 확보 시 확인할 묶음

| 묶음 | 필요한 구조 | 실패하면 할 일 |
| --- | --- | --- |
| 흉부 관찰 | C01~C04, T01~T07 | 누락된 구조의 설명·문제를 보류 |
| 복부 관찰 | C01, C03, C04, T07, A01~A09 | 복부 과정 공개를 보류하고 흉부 흐름부터 검토 |
| 흉부 분리 | T01~T03과 기준 윤곽 | 연결 구조 처리까지 정한 후 사용 |
| 복부 분리 | A01~A09 중 검수한 그룹 | 일괄 방사형 분리를 적용하지 않고 경로 재설계 |

원본 자료 후보는 [자료 조사](04-research-and-assets.md)의 BodyParts3D와 Z-Anatomy다. 후속 작업에서 두 후보의 배포본을 확보하고 BodyParts3D 흉부 10개 그룹의 ID 매핑·형상 검사를 진행했다. C03은 흉추 구간으로 검토했고 C01 몸통 윤곽은 미확보다. [검사 결과](14-sample-quality-review.md)를 따른다. 이 목록이나 파일 검사만으로 의학적 적합성을 승인하지 않는다.

## 과정과 구조의 연결

| 과정 ID | 용도 | 내용 | 사용 구조 | 완료 과제 |
| --- | --- | --- | --- | --- |
| EXP01 | 탐색 | 가슴 부위에서 원하는 구조 찾기 | C01~C04, T01~T07 | 선택·회전·복원 후 장면 저장 |
| LRN01 | 학습 | 방향과 주요 구조 식별 | C01~C03, T01~T03 | 이름 라벨 없이 지정 구조 선택 |
| LRN02 | 학습 | 가려진 구조 관찰과 원위치 복귀 | C01~C04, T01~T07 | 분리와 정상 배치를 구분 |
| LRN03 | 학습 | 복부 구조 탐색 | A01~A09 및 주변 맥락 | 검색·다른 시점 관찰·오답 재방문 |
| PRE01 | 설명 | 가슴 전체 → 관심 구조 → 정상 배치 | C01~C04, T01~T07 | 장면 3개로 상대방에게 설명 |
| PRE02 | 설명 | 복부의 관심 구조 표시 | A01~A09 및 주변 맥락 | 강조·포인터·저장 시점 복귀 |

LRN03·PRE02는 복부 모델 확보 후 진행한다. 모든 과정에서 학습과 설명이 각각 독립적으로 끝나야 한다. 설명 사용자에게 퀴즈 완료를 요구하지 않는다.

## 콘텐츠 한 항목의 작성 기준

이름·동의어·부위·계통·모델 연결 외에 다음을 준비한다.

- 한 문장 요약과 상세 설명을 분리한다.
- 설명할 주변 관계와 함께 보여 줄 구조를 지정한다.
- 기본 시점, 숨김 허용 그룹, 분리 가능 여부를 적는다.
- 문항에는 정답 ID·해설·정답이 노출되지 않는 화면 조건을 함께 적는다.
- 출처, 사용권, 검수 상태, 버전을 기록한다.

검수 상태는 ‘작성 중 → 검토 요청 → 수정 필요 또는 공개 가능’으로 관리한다. 공개 가능 항목만 실제 사용자용 과정에 연결한다. 현재 목록과 문제 예시는 모두 작성 중이다.

## 이번 결정과 남은 확인

작업용 기준으로 정한 것: 세 사용 흐름, 흉부 우선, 20개 후보 단위, 내부 체험판 범위.

외부 확인이 필요한 것: 모델에서 실제 추출 가능한 구조, 한국어 표기, 분리 경로의 정확성, 상세 관계·기능 설명, 공개·출력 권리. 실제 사용자 테스트·전문가 검수·개발·구매는 이 문서 작성에 포함하지 않았다.
