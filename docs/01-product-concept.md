# 서비스 컨셉과 초기 범위

## 제안하는 서비스

최종 목표는 웹 공개와 앱 스토어 등록을 마쳐 실제 학습자가 이용할 수 있는 서비스로 출시하는 것이다. 현재는 기획 단계이며, 2차 검토 결과는 [기획 검증](07-second-review.md)과 [출시 계획](08-release-plan.md)에 반영했다.

**장기와 근육을 직접 돌리고 벌려 보면서 인체를 탐색·학습하고, 다른 사람에게 위치·구조·관계를 시각적으로 설명하는 한국어 중심 3D 인체 도구.**

사용자 확인에 따라 공부 전용으로 한정하지 않는다. 의사가 환자에게 설명하거나, 교수자·일반인이 강의와 대화에서 자료로 보여 주는 용도를 함께 설계한다. 첫 화면은 ‘자유 탐색·학습·설명’ 세 경로를 제안한다. 구체적인 설명 모드와 자료 활용은 [용도 확장](09-exploration-and-presentation.md)을 따른다.

‘의학 전체’를 처음부터 다루기보다 정상 인체의 육안해부학으로 시작한다. 구조를 배우는 해부학과 작동 원리를 배우는 생리학을 연결하되, 초기 학습 목표는 구조물의 식별과 위치 관계 이해로 한정한다.

요청한 ‘입체적으로 돌려 보기’는 일반 화면에서 조작하는 실시간 3D로 해석한다. 양안 입체영상이나 VR 기기는 이후 선택 기능이다. ‘밀고 당기기’는 구조물 사이 간격을 조절하는 기능으로 설계한다. 실제 조직을 눌렀을 때 변형되는 물리 시뮬레이션은 별도 범위다.

## 대상 사용자 가정

| 사용자 | 필요한 경험 | 초기 적용 |
| --- | --- | --- |
| 해부학을 처음 접하는 대학생·성인 | 쉬운 이름, 위치 안내, 짧은 학습 단위 | 핵심 대상 |
| 간호·보건계열 입문 학습자 | 한글·영문 용어, 계통 분류, 확인 문제 | 핵심 대상과 함께 검증 |
| 의대·치대의 상세 해부학 학습자 | 세부 신경·혈관, 변이, 임상 연결 | 확장 후보 |
| 물리치료·운동 분야 학습자 | 근육 부착, 관절 운동, 신경 지배 | 근골격계 확장 후보 |
| 의사 등 설명하는 전문가 | 빠른 부위 검색, 강조, 환자 눈높이 설명 | 초기 설명 흐름 검증 대상 |
| 교수자·발표자 | 장면 순서 구성, 큰 화면 표시 | 초기 설명 흐름 검증 대상, 과제 관리는 후속 |
| 일반인 | 인체 탐색, 가족·상대방에게 보여 주기 | 초기 탐색·설명 검증 대상 |

학습자뿐 아니라 설명하는 사람과 설명을 듣는 사람을 구분해 검증한다. 학습과 설명 중 출시 시 어느 흐름에 더 많은 콘텐츠를 배정할지는 미정이지만, 설명 용도 자체를 후속으로 제외하지 않는다.

## 핵심 학습 경험

1. ‘가슴 속 장기’ 같은 쉬운 주제를 고른다.
2. 모델을 앞·옆·뒤에서 돌려 관찰한다.
3. 가리는 구조물을 숨기거나 반투명하게 만든다.
4. 분리 슬라이더로 간격을 벌려 숨은 구조물을 찾는다.
5. 원위치로 되돌려 정상 배치를 확인한다.
6. 이름 찾기와 위치 관계 문제를 풀고 틀린 장면을 다시 본다.

학습 효과는 아직 입증한 것이 아니다. 특히 분리된 상태만 기억하지 않도록 복귀 단계를 학습 과정에 포함한다.

## 차별화 가설

기존 제품에도 해부 탐색, 교육 콘텐츠와 퀴즈가 있다. 기능 수보다 **쉬운 한국어 안내, 간격 조절의 명확한 사용법, 정상 위치로 돌아가 확인하는 학습 과정**에 집중한다. Complete Anatomy와 Visible Body의 기능은 [공식 소개](https://www.elsevier.com/products/complete-anatomy), [Visible Body Suite](https://www.visiblebody.com/practitioners)에서 확인할 수 있다.

한국어만으로 차별화가 충분하다고 단정하지 않는다. 국내 MEDIP Box도 디지털 해부학 교육을 제공한다. 개인이 웹과 휴대전화에서 짧게 반복 학습할 수 있는 경험의 수요를 확인해야 한다. [MEDICAL IP 공식 발표](https://medicalip.com/newsview/700/)

## 첫 학습 묶음 제안

흉부·복부 주요 장기를 중심으로 **20~30개 선택 단위, 3개 학습 과정, 15~20개 문제**를 내부 체험판의 기획 가정으로 둔다. 정식 출시 분량은 별도로 결정한다. 정확한 수는 모델의 분할 상태와 전문가 검토 후 정한다. 모델 오브젝트 수와 학습 항목 수는 일치하지 않을 수 있다.

- 과정 1: 인체의 앞·뒤·좌·우와 주요 장기 찾기.
- 과정 2: 흉곽·폐·심장을 관찰하고 가려진 구조를 찾기.
- 과정 3: 복부 장기를 다른 각도에서 보고 정상 배치로 복귀하기.

근육 학습은 어깨 또는 무릎 한 부위로 확장한다. 전신의 모든 근육과 혈관을 처음부터 포함하면 설명·선택·검수 범위가 크게 늘어난다.

## 웹과 앱의 역할 제안

| 환경 | 우선 경험 | 후속 검증 |
| --- | --- | --- |
| PC 웹 | 큰 화면 탐색, 설명과 모델 동시 보기 | 마우스 조작, 라벨 밀도 |
| 태블릿 | 터치로 탐색하고 수업에서 활용 | 손가락 가림, 가로·세로 전환 |
| 휴대전화 | 짧은 복습, 검색, 저장한 장면 재방문 | 작은 구조물 선택, 발열·성능 |
| 설치형 앱 | 복습 접근성, 필요 시 오프라인 학습 | 모델 저장 권리, 용량, 동기화 |

기획은 공통 학습 경험부터 만든다. 웹을 먼저 구현할지, 앱과 동시에 출시할지, 어떤 기술을 쓸지는 지금 확정하지 않는다.

## 초기 포함과 확장

| 초기 핵심 | 다음 단계 | 장기 검토 |
| --- | --- | --- |
| 회전·확대·이동, 구조 선택 | 단면과 내부 구조 학습 | 실제 영상 연계 |
| 숨김·단독 보기·투명도 | 근육 부착과 관절 운동 | 조직 변형 시뮬레이션 |
| 간격 조절·원위치 복귀·되돌리기 | 학습 장면 공유 | 교수자 수업 관리 |
| 한국어·영문 라벨, 짧은 설명 | 선택 계정과 기기 간 기록 동기화 | AR·VR |
| 이름·위치 관계 문제, 오답 복습 | 다양한 체형·해부학 모델 | 질환·시술 교육 |
| 기기 내 장면 저장·이어하기, 손님 학습 | 학습 묶음 다운로드와 오프라인 확장 | 개인화된 학습 추천 |

표의 초기 핵심은 정식 첫 출시 기준의 제안이다. 내부 체험판에서는 저장·복습을 간단한 시나리오로 검토할 수 있다. 모델 재배포 권리와 모바일 조작 성능은 앱 개발 방식 선택 전에 확인한다.

수익 모델은 미정이다. 개인 구독, 학습 묶음 판매, 기관 이용권은 사용자와 콘텐츠 원가가 확인된 뒤 비교한다.
