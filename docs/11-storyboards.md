# 탐색 학습 설명 스토리보드

작성일: 2026-11-06. 연결 이슈: [#2](https://github.com/Yongyeon-Kim/anatomy-3d/issues/2). 구조 ID와 과정 ID는 [콘텐츠 범위](10-content-scope.md)를 따른다. 실제 화면 구현이나 사용자 실험 결과가 아닌 장면별 기획이다.

## 공통 시작

첫 화면은 ‘자유 탐색’, ‘학습’, ‘설명 준비’로 나눈다. 가입 없이 시작할 수 있다. 최근 장면·이어하기는 저장 기록이 있을 때만 보여 준다. 처음 선택한 직업이나 신분으로 기능을 제한하지 않는다.

## 자유 탐색 EXP01

| 단계 | 사용자 행동 | 화면과 상태 변화 | 다음 행동 |
| --- | --- | --- | --- |
| E1 | 자유 탐색에서 가슴 선택 | 정상 배치와 방향 표시, 부위 목록 노출 | 회전 또는 검색 |
| E2 | ‘폐’ 검색 | 좌우 후보 목록, 인체 기준 좌우 표시 | T02 또는 T03 선택 |
| E3 | 구조 선택 | 선택 강조, 기본 설명, 해당 부위를 화면 중앙에 배치 | 회전·확대 |
| E4 | 흉곽 투명도 조절 | 관심 구조와 주변 맥락 함께 표시 | 분리 보기 진입 |
| E5 | 분리 슬라이더 이동 | 선택 부위에만 분리 적용, 분리 상태 표시 | 원위치와 비교 |
| E6 | 배치 복원 | 시점을 유지하고 구조 위치 복원 | 저장 또는 종료 |
| E7 | 장면 저장 | 자동 이름 제안, 기기 내 저장 완료 표시 | 다시 열기 또는 설명 모드 |

검색 취소 시 이전 선택·시점으로 돌아간다. 검색 결과를 고른 뒤 장면 복귀를 누르면 검색 전 상태를 복원한다. 결과가 없으면 비슷한 이름 또는 부위 탐색을 제공하며 임의의 장기를 선택하지 않는다.

## 학습 LRN01과 LRN02

| 단계 | 사용자 행동 | 화면과 상태 변화 | 기록 |
| --- | --- | --- | --- |
| L1 | 가슴 기본 구조 과정 시작 | 목표와 사용할 조작 2~3개 안내 | 과정 시작 |
| L2 | 안내된 구조 선택 | 해당 구조와 쉬운 이름 표시 | 관찰 완료 |
| L3 | 다른 시점으로 회전 | 인체 방향 표시는 유지 | 진도만 기록 |
| L4 | 분리 후 원위치 비교 | 두 상태의 차이를 안내 | 배치 비교 단계 완료 |
| L5 | 확인 문제 시작 | 정상 배치 복원, 이름·검색·설명 힌트 숨김 | 문제 시작 |
| L6 | 구조를 선택해 제출 | 정답 여부·해설·관련 구조 표시 | 답안 기록 |
| L7 | 틀린 항목 다시 보기 | 관찰 화면으로 복귀 | 복습 목록 추가 |
| L8 | 종료 후 다시 열기 | 이어하기와 오답 복습 중 선택 | 저장된 단계 복원 |

문제에 들어갈 때 기존 탐색 장면은 임시 보관한다. 문제를 나가면 원래 장면으로 복귀한다. 중간에 나간 문제는 오답으로 기록하지 않고 ‘미완료’로 둔다.

## 문제 예시

내용은 검수 전 초안이다. 이름 문제의 ID 연결도 실제 모델 대응 확인 후 확정한다.

| ID | 제시 문구 초안 | 답안과 설명 방식 | 확인할 사항 |
| --- | --- | --- | --- |
| Q01 | 심장을 선택하세요 | T01 선택, 이름과 기본 설명 표시 | 모델 ID·라벨 정확성 |
| Q02 | 인체의 왼쪽 폐를 선택하세요 | T02 선택, 인체 기준 좌우를 설명 | 화면 좌우와 혼동 유도하지 않기 |
| Q03 | 원래 배치를 보여 주는 장면을 고르세요 | 같은 장면의 분리 0 상태 선택 | 단순 색 차이가 정답 단서가 되지 않기 |
| Q04 | 방금 찾은 구조를 다른 시점에서도 찾아보세요 | 이전 정답 ID를 유지한 채 시점만 변경 | 선택 가능성과 가려짐 검토 |

Q03은 조작과 표시 상태의 이해를 확인하며 의학적 위치 지식 평가를 대체하지 않는다. 앞뒤·인접 관계 문항은 전문가가 관계 설명을 확정한 다음 추가한다.

LRN03은 복부에서도 동일한 과정을 적용한다. 예를 들어 A03을 관찰하고 다른 시점에서 다시 고른다. 모델이 제공하지 않는 내부 구조 문제는 만들지 않는다.

## 의사와 일반인의 설명 PRE01

상황: 설명자가 태블릿 또는 PC에서 가슴의 특정 구조를 청자에게 보여 준다. 환자 개인 정보를 입력하지 않고 일반 모델을 사용한다.

| 장면 | 준비 상태 | 설명 중 행동 | 복귀와 종료 |
| --- | --- | --- | --- |
| P1 전체 위치 | C01~C04와 T01~T07, 정상 배치 | 가슴 부위와 관심 구조를 포인터로 가리킴 | 저장 시점 버튼으로 복귀 |
| P2 관심 구조 | T01 강조, 주변 구조 투명도 조정 | 회전해 다른 각도 설명, 필요할 때만 묶음 분리 | 원위치 미리보기 또는 배치 복원 |
| P3 전체 속에서 다시 확인 | 정상 배치, T01 강조, 필요한 라벨만 표시 | 청자에게 같은 구조를 가리켜 보도록 요청 | 설명 종료·장면 저장 |

설명 준비에서 P1→P2→P3 순서를 저장한다. 발표 중 자유 회전해도 원본 장면을 자동 덮어쓰지 않는다. ‘현재 상태로 장면 수정’을 명시적으로 선택해야 저장한다.

설명 모드에는 점수·오답·진도 표시가 없다. 쉬운 이름·전문 이름 전환, 강조, 포인터, 이전·다음 장면, 저장 시점 복귀를 우선 노출한다. 화면 공유나 프로젝트 출력은 향후 환경 검증 대상이며 이번에 구현하지 않는다.

## 일반인의 즉석 설명 PRE02

복부 선택 → 관심 구조 검색 → 강조 → 상대방에게 화면 보여 주기 → 회전·포인터 사용 → 기기 내 장면 저장으로 끝난다. 미리 장면을 세 개 만들 필요는 없다. 공개 링크·이미지 출력이 아직 지원되지 않는 단계에서는 ‘기기에 저장’만 제공한다.

## 실패와 복구

| 상황 | 안내 | 복구 상태 |
| --- | --- | --- |
| 3D 로딩 실패 | ‘모델을 불러오지 못했습니다’와 재시도·설명 보기 | 기존 진도와 장면 보존 |
| 저장 실패 | 저장되지 않았음을 알리고 다시 저장 | 화면은 유지, 완료 표시하지 않음 |
| 선택 구조가 가려짐 | 후보 목록 또는 주변 투명도 조절 | 원래 장면으로 복귀 가능 |
| 모델 버전에서 저장 ID 누락 | 일부 장면을 복원하지 못했다고 표시 | 새 기본 장면 제안, 원본 저장 항목 보존 |
| 발표 중 앱 중단 | 최근 정상 저장 장면 선택 제공 | 저장하지 않은 변경은 복원 보장하지 않음 |

## 후속 검증 과제

탐색자는 E1~E7을, 학습자는 L1~L8을, 설명자는 P1~P3을 진행한다. 진행자는 도움을 준 단계, 혼동한 용어, 예상하지 못한 화면 변화를 기록한다. 청자에게는 설명된 구조를 다시 가리켜 달라고 요청한다. 성공률과 소요시간은 실제 검증 후 기록하며 현재 문서에 결과로 채우지 않는다.
