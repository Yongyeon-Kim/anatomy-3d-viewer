# 경쟁 앱 검토: Anatomy 3D Atlas

조사일: 2026-11-06. 사용자 제공 앱: Catfish Animation Studio의 [해부학 - 3D 아틀라스](https://play.google.com/store/apps/details?id=com.catfishanimationstudio.MuscularSystemLite&hl=ko).

공식 소개·기능 안내·FAQ와 Google Play 스크린샷 2장을 확인했다. 앱을 설치하거나 결제하여 조작한 결과는 아니다. 스크린샷은 로컬 조사 폴더에서 확인했으며 저장소에는 분석 문서만 올린다.

## 판단

우리 서비스의 시각 품질과 기본 탐색 기능을 비교할 주요 경쟁 사례로 삼는다. 현재 무료 샘플의 단순 미리보기보다 완성된 표현을 보여 준다. 다만 완성 앱의 홍보 이미지와 기본 메시 검사용 렌더를 비교한 것이므로 원본 모델 자체의 품질 우열이나 같은 품질 달성 가능성을 확정하지 않는다.

우리 기획에서는 **기관 사이 간격 조절, 쉬운 설명 화면, 설명 장면 저장·공유**를 검증할 핵심 경험으로 유지한다. 경쟁사의 해당 기능이 없다는 결론이 아니라, 우리 사용자가 체감할 차이를 직접 검증하자는 제안이다.

위 기능은 [제작사 기능 안내](https://anatomy3datlas.com/features/)에 근거한다. 간격을 연속적으로 벌리는 기능은 확인한 자료에서 찾지 못했으며, 미지원으로 확정하지 않는다.

제작사는 상세 모델의 메모리·처리 부담 때문에 전신을 부위별로 나누었다고 설명한다. 전체 콘텐츠는 구독 방식이며 운영체제별 이용권이 구분된다고 안내한다. 이는 해당 앱의 정책이다. [공식 FAQ](https://anatomy3datlas.com/support/)

## 스크린샷에서 직접 관찰한 시각 품질

Google Play의 몸통·심장 스크린샷을 확대해 확인했다. 아래는 외관 관찰이며 의학적 정확성 판정이 아니다. [Google Play 스크린샷 제공 페이지](https://play.google.com/store/apps/details?id=com.catfishanimationstudio.MuscularSystemLite&hl=ko)

- 몸통: 근육의 길이 방향 결, 힘줄과 뼈의 표면 차이, 색으로 구분된 혈관·신경이 보인다.
- 심장: 내부를 노출한 형태, 판막 주변의 가는 구조, 표면 요철과 여러 위치의 핀이 보인다. 이 이미지로 실시간 절단 기능까지 확인할 수는 없다.
- 화면: 검은 배경에 구조물을 크게 배치한다. 하단 조작 버튼과 여러 핀은 화면 면적을 상당히 차지한다. 한글·영문 용어를 함께 보여 주는 장면도 있다.

시각적 완성도는 폴리곤 수 하나로 설명할 수 없다. 우리 샘플에서는 실루엣, 구조별 색·재질, 조명, 표면 보정, 라벨 가독성을 각각 개선·평가해야 한다. 스크린샷만으로 경쟁사의 텍스처 해상도나 렌더링 기술은 특정하지 않는다.

## 우리 기획에 반영할 제안

### 1. ‘분리’라는 표현을 나누기

- **선택만 보기:** 선택한 기관 이외의 구조물을 숨긴다.
- **간격 벌리기:** 여러 기관의 위치를 설명용으로 벌린다. 원래 위치와 벌어진 위치를 구분하고 한 번에 복원한다.
- **층별 보기:** 표면에서 안쪽으로 구조를 순서대로 감춘다.

간격 조절에는 확대와 다른 입력을 배정한다. 모바일의 두 손가락 확대는 유지하고, 간격은 별도 슬라이더로 시작하는 방안을 우선 검토한다. 기하학적 이동을 실제 조직의 신축·변형처럼 설명하지 않는다. 기존 [조작 명세](12-screen-and-interaction-spec.md)를 보완할 제안이며 구현 결정은 아니다.

### 2. 설명할 때 보이는 정보 줄이기

의사가 환자에게 보여 주거나 일반인이 설명하는 상황에는 선택한 구조와 필요한 라벨만 남기는 설명 모드를 우선한다. 전문 용어·쉬운 표현을 전환하고, 장면을 단계별로 저장해 같은 설명을 반복할 수 있게 한다. 핀 크기·겹침·표시 개수도 품질 검토에 포함한다. 경쟁 앱의 설명 모드 지원 여부와 무관한 우리 사용성 제안이다.

### 3. 무료 모델의 완성 가능성을 작은 범위에서 먼저 검증하기

유료 모델 제외 조건을 유지한다. [확보한 Z-Anatomy 폐 외형](16-free-model-review.md)을 우선 후보로 삼아 기본 메시와 표면 보정 결과를 같은 카메라·조명에서 비교하는 것이 다음 작업으로 적합하다. 모델을 더 많이 확보하는 것과 별도로, 한 기관을 설명 자료로 쓸 만큼 개선할 수 있는지 판단해야 한다.

품질 비교에는 외곽선, 엽 경계, 확대했을 때의 면·음영, 기관 구분, 작은 화면에서의 식별성을 사용한다. 표면을 부드럽게 만든 결과가 해부학적 경계를 흐리는지도 따로 검토한다. 동일 품질을 무료 자산만으로 달성할 수 있다는 보장은 아직 없다.

### 4. 전신 개요와 상세 모델 분리하기

우리 서비스는 가벼운 전신 개요에서 부위를 고른 뒤 해당 부위의 상세 모델을 불러오는 방안을 검토한다. 흉부부터 검증하고, 실제 기기에서 로딩 시간·메모리·회전 반응을 측정한 후 상세 범위를 늘린다. 이는 경쟁사 FAQ를 참고한 설계 제안이며 아직 성능 측정은 하지 않았다.

## 아직 확인하지 못한 것

실제 기기의 조작감·프레임률·오프라인 범위, 모든 구조의 의학적 정확성, 간격 조절 유무, 장면 공유·발표 기능의 상세 동작은 확인하지 않았다. 사용자 리뷰의 정확성 관련 주장은 재현하지 않았으므로 결함으로 확정하지 않는다. 스토어 스크린샷이 현재 설치 버전과 완전히 동일한지도 확인하지 않았다.

이번 작업은 경쟁 자료 조사와 기획 보완안 작성까지다. 무료 모델 가공, 제품 개발, 앱 설치·결제는 진행하지 않았다.

추가 조사에서 과거 iOS 버전의 Unity 사용 기록을 확인했다. VOKA도 설명·공유 도구를 소개하므로 설명 기능 자체를 독점적 차별점으로 가정하지 않는다. 근거와 후보 재평가는 [Unity·VOKA·Open3DModel 검증](18-unity-voka-open3dmodel-review.md)에 기록했다.
