# 학습 카테고리와 콘텐츠 구성

## 두 가지 탐색 경로

초보자에게는 ‘몸의 어디를 볼까요?’라는 **부위별 보기**를 기본으로 제공하고, 교과 학습에는 **계통별 보기**를 제공한다. 같은 장기와 설명을 두 경로에서 재사용한다.

‘내장’은 쉬운 진입 메뉴로 쓸 수 있지만, 정식 계통 하나로 취급하지 않는다. 계통 분류와 인체의 조직 단계는 [OpenStax 인체 구성](https://openstax.org/books/anatomy-and-physiology-2e/pages/1-2-structural-organization-of-the-human-body)을 참고했다. 아래의 메뉴 구성과 우선순위는 제품 기획안이다.

## 계통별 메뉴 제안

| 쉬운 진입 이름 | 학습 분류 | 대표 콘텐츠 | 공개 순서 제안 |
| --- | --- | --- | --- |
| 뼈와 관절 | 골격계·관절 | 뼈, 연골, 인대 | 초기 장기의 위치 기준 → 상세 확장 |
| 근육 | 근육계 | 골격근, 힘줄, 부착 부위 | 다음 학습 묶음 |
| 심장과 혈관 | 심혈관계 | 심장, 주요 혈관 | 심장 중심 초기 |
| 숨쉬기 | 호흡계 | 기관, 기관지, 폐 | 주요 구조 초기 |
| 음식이 지나가는 길 | 소화계 | 식도, 위, 장, 간, 담낭, 췌장 | 주요 장기 초기 |
| 소변이 만들어지는 길 | 비뇨계 | 신장, 요관, 방광 | 초기 범위 후보 |
| 뇌와 신경 | 신경계 | 뇌, 척수, 말초신경 | 후속 |
| 림프와 면역 | 림프계·면역 관련 구조 | 림프관, 림프절, 비장 | 후속 |
| 호르몬 | 내분비계 | 갑상샘, 부신 등 | 후속 |
| 생식과 발생 | 생식계, 발생학 별도 과정 | 생식기관, 임신 단계 | 후속 |
| 피부 | 외피계 | 피부와 부속 구조 | 후속 |
| 눈과 귀 | 특수감각 학습 묶음 | 눈, 귀 | 후속 |

이 표는 교과서의 계통 수를 그대로 재현한 표가 아니다. 관절·감각·발생은 학습 편의상 별도 묶음으로 제시한다. 췌장처럼 여러 계통에서 다루는 구조는 한 카테고리에만 고정하지 않는다.

## 부위별 메뉴 제안

| 메뉴 | 초보자가 할 수 있어야 하는 일 |
| --- | --- |
| 전신 | 주요 장기가 어느 부위에 있는지 찾기 |
| 머리와 목 | 뇌·감각기관·기도의 큰 위치 파악 |
| 가슴 | 흉곽과 주요 장기의 배치 관찰 |
| 배 | 복부 주요 장기를 앞·옆·뒤에서 식별 |
| 골반 | 비뇨·생식 구조의 위치 관찰 |
| 등과 척추 | 척추와 주변 구조의 층 관계 관찰 |
| 팔과 손 | 뼈·관절·근육 관계 학습 |
| 다리와 발 | 뼈·관절·근육 관계 학습 |

처음부터 세부 메뉴를 모두 활성화하지 않는다. 초기 공개 범위를 가슴·배 중심으로 표시하고, 나머지는 기획 목록으로 관리한다.

## 장기와 근육은 설명 구조를 다르게 설계

| 장기 설명 카드 | 근육 설명 카드 |
| --- | --- |
| 이름과 위치 | 이름과 위치·깊이 |
| 주요 기능 한두 문장 | 기시·정지 또는 부착 부위 |
| 주변 구조와의 관계 | 관련 관절과 작용 |
| 내부 구분은 확대 학습에서 제공 | 신경 지배는 심화 단계에서 제공 |
| 연결되는 통로·혈관 | 관련 뼈·힘줄·주변 근육 |

‘근육을 벌려 보기’는 층을 구분하는 학습이다. ‘근육이 수축하며 관절이 움직이는 모습’은 별도 동작 학습이다. 두 기능을 같은 것으로 설명하지 않는다.

## 용어와 구조물 정보

화면에는 쉬운 한국어 이름과 영문을 함께 제공하고 검색에는 동의어를 허용한다. 예를 들어 ‘신장’과 ‘콩팥’, ‘폐’와 ‘허파’를 같은 구조에 연결하는 방식을 검토한다. 최종 대표 표기와 용어집 판본은 한국어 의학 검수자가 확정한다.

영문·라틴어 용어 및 구조 식별자 연결에는 TA2와 관련 용어 자료를 검토한다. IFAA는 TA2와 TA2Viewer를 소개하고 있다. 이 자료가 한국어 표기를 결정해 주는 것은 아니다. [IFAA 공식 안내](https://ifaa.net/2022/08/12/report-of-the-federative-international-programme-on-anatomical-terminologies-fipat/)

콘텐츠 한 항목에는 다음 정보를 준비한다.

- 고유 식별자, 대표 이름, 영문, 검색 동의어, 좌우 구분.
- 소속 계통과 부위, 상위·하위 구조, 연결되는 모델 항목.
- 기능 요약, 주변 관계 설명, 기본 관찰 방향.
- 원위치와 분리 보기 대상 그룹, 학습 문제 연결.
- 출처와 판본, 작성자·검수자, 검수일·수정 이력.

방향 표시는 관찰자의 좌우가 아니라 인체 기준으로 유지한다. 화면을 돌려도 인체의 왼쪽·오른쪽 표시가 뒤집히면 안 된다. 방향과 단면 학습의 참고 기준은 [OpenStax 해부학 용어](https://openstax.org/books/anatomy-and-physiology-2e/pages/1-6-anatomical-terminology)다.
