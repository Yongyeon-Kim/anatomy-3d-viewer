## 조사 결과의 한계

- 제품 소개는 공급자의 설명이며, 조작 편의성과 교육 효과를 독립적으로 확인한 결과는 아니다.
- 모델 파일의 형상, 내부 구조, 개별 선택 가능 범위, 모바일 성능은 아직 검사하지 않았다.
- BioDigital 개발자 사이트는 검색에 문서 내용이 나타나지만 직접 열람 시 계정 선택 화면으로 표시됐다. 세부 조작 지원은 미확정으로 두었다.
- 한국어 표준 용어집의 최신 판본과 대량 재사용 조건은 확정하지 않았다.
- OpenStax의 예전 배포본과 현재 페이지의 조건을 혼용하지 않는다. 실제 사용하는 판본의 조건을 별도로 기록한다.
- 라이선스 표는 공개 안내를 요약한 것이며 개별 파일·계약의 전체 조건을 대체하지 않는다.
- 첫 구조물 수, 학습 과정 수, 기획 기간은 제안치다. 사용자가 확정한 요구사항이나 조사로 입증된 수치가 아니다.

원문 전체, 교재 그림, 유료 서비스 화면, 3D 자산은 이 폴더에 복제하지 않았다. 출처별 요약과 기획안을 저장했다.
