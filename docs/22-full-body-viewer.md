# 전신 3D 탐색 시제품

[전신 탐색 #21](https://github.com/Yongyeon-Kim/anatomy-3d/issues/21)의 로컬 구현이다. 기존 Z-Anatomy 고정 원본을 사용한다.

## 들어가는 방법

로컬 개발 서버를 열면 전신 개요를 오른쪽 위에서 비스듬히 내려다보는 시점으로 표시한다. 모델에서 부위를 선택하고 상단의 **열기**를 누르거나, 왼쪽 부위 목록과 상단 **부위 선택**에서 바로 이동한다. 상세 화면의 **전신 개요** 버튼으로 돌아갈 수 있다. 상세 주소는 `/?region=left-arm`과 같은 형태다. 브라우저의 뒤로 가기와 앞으로 가기는 부위를 복원한다.

모든 부위에서 회전·확대, 앞·뒤·옆, 구조 선택, 숨김·단독 보기, 간격 조절·배치 복원을 사용한다. 선택한 구조는 원래 색과 라임색을 번갈아 표시한다. 동작 줄이기 설정이 켜져 있으면 라임색을 유지한다. 목록은 한국어 이름, 등록된 동의어와 영문 원본 이름으로 검색한다. 좌우는 인체 기준이다. 좌우 팔·손에는 손바닥·손등 관찰 버튼을, 좌우 다리·발에는 발등·발바닥 관찰 버튼을 제공한다.

왼쪽 **보기 조작**에서 선택 중심으로 보기, 선택만 보기, 선택 숨기기와 전체 다시 표시를 사용한다. 오른쪽 **해부학 설명**에는 선택한 구조의 한국어·영문 이름, 위치, 역할과 참고 출처가 표시된다. 여러 구조가 들어 있는 묶음은 **구성 구조**에서 전체 묶음과 개별 구조를 전환한다. 상세 부위와 전신 개별 배치에서는 모델을 눌러 개별 구조를 선택할 수 있다. 예를 들어 얕은 등 근육에는 좌우 등세모근의 내림·가로·오름부분과 좌우 넓은등근이 연결돼 있다. [등세모근 해부 연구](https://pubmed.ncbi.nlm.nih.gov/23916077/) · [OpenStax 어깨대와 위팔 근육](https://openstax.org/books/anatomy-and-physiology-2e/pages/11-5-muscles-of-the-pectoral-girdle-and-upper-limbs)

9개 상세 부위의 구성 구조는 위치와 역할 설명을 제공한다. 전신 혈관은 주요 항목부터 개별 설명을 제공하고, 그 밖의 항목은 원본 이름과 동맥·정맥 묶음 설명을 표시한다.

구조를 선택하면 오른쪽 설명 위에 원본 배치로 그린 도판을 표시한다. 묶음과 개별 구조를 바꾸면 도판도 갱신된다. 등·척추는 후면, 심장은 앞 사선, 식도는 기관과 구분되는 뒤 사선에서 보여준다. 선택한 위치는 지시선과 갈색 강조로 표시한다. [도판 제작·출처 기록](23-follow-up-verification.md#도판과-설명-장면)

뷰어 아래 **설명 장면**에서 현재 장면을 이 브라우저에 저장하고 다시 열 수 있다. 링크에는 부위, 선택, 구조별 표시 상태, 간격, 관찰 방향과 GLB의 SHA-256을 기록한다. 다른 기기에서 같은 링크를 열려면 대상 주소에 접속할 수 있어야 한다. 이미지 저장은 현재 3D 시점을 PNG 파일로 내려받는다.

전신과 상세 부위에서 초기 간격은 20%이며 **화면 초기화**를 누르면 20%로 돌아간다. 전신에서는 간격을 40%까지 늘리면 부위별로 움직이고, 40%를 넘으면 뼈·장기·복벽 등 212개 구조가 각자 다른 위치로 점차 벌어진다. 혈관은 동맥과 정맥 묶음으로 이동한다. 개별 배치를 조절하는 동안 관찰 방향을 유지하며 벌어진 모델을 화면에 맞춘다. **배치만 복원**은 원래 위치를 복원하고 보는 방향과 확대 상태를 유지한다.

전신을 열면 골격·장기·복벽과 혈관이 함께 보인다. **전신 구조**와 **전체 혈관** 버튼은 독립적으로 켜고 끌 수 있다. 전신 구조를 끄면 혈관을 단독으로 볼 수 있다. 복벽 근육과 배가로근막, 동맥과 정맥도 각각 조작할 수 있다. 복부 목록에서는 혈관 두 개와 근육 네 묶음을 각각 선택할 수 있다. 흉부에는 주요 혈관 버튼을, 좌우 팔·다리에는 주요 동맥 버튼을 제공한다. 각 화면을 열거나 **화면 초기화**를 누르면 해당 모델의 모든 구조가 기본 재질로 표시된다. [혈관 #31](https://github.com/Yongyeon-Kim/anatomy-3d/issues/31) · [복벽 #32](https://github.com/Yongyeon-Kim/anatomy-3d/issues/32) · [빠른 표시 #33](https://github.com/Yongyeon-Kim/anatomy-3d/issues/33)

부위별 실제 오브젝트 이름, 좌우, 기본 시점, 표시 묶음, 동의어와 원본 버전은 [부위 자산 명세](../research/results/region-manifest.json)에 있다. 부위 사이에 공유되는 뼈와 횡격막 등의 원본 변환을 대조한다. 전신 개요의 큰 메시와 복벽 근육 8개 표면은 웹 전송량을 줄이기 위해 간소화한다. 복부 모델의 원래 19개 메시와 같은 위치에 복부 혈관과 복벽을 추가했으며, 이 환경에서 복부 GLB는 약 2.76 MB에서 3.75 MB로 늘었다.

흉부 식도의 아래끝은 횡격막 경계 상자 안에서 복부 위 표면과 원본 좌표 0.00020 이내에 놓인다. 횡격막과 첫째 허리뼈의 공통 변환도 자동 검사한다. 흉부·복부 자산의 구조 누락과 보완 후보는 [자산·검증 기록](23-follow-up-verification.md#자산과-부위-경계)에 정리했다.

## 재현과 검증

1. [원본 자산 준비](../research/README.md#전신-및-부위별-자산)에 따라 Blender에서 GLB와 검사 기록을 만든다.
2. `npm ci` 후 `npm run dev`를 실행한다.
3. `npm test`, `npm run test:browser`, `npm run build`를 실행한다. 빌드를 띄운 뒤 `npm run test:production`으로 전신과 상세 부위를 확인한다. Chromium 설치는 `npx playwright install chromium`을 사용한다.

브라우저는 전신에서 9개 상세 부위로 이동하고 한 번에 선택한 파일을 요청한다. 자동 검사는 모든 부위의 원본 좌표와 배치 복원, 전신 구조와 전체 혈관의 독립 표시, 데스크톱·터치 에뮬레이션의 이동·선택·숨김, 빠른 전환의 이전 요청 취소, 직접 링크·브라우저 뒤로 가기, 로딩 오류 복구를 확인한다. 전신 GLB는 이 환경에서 약 20.1 MB이며, 머리·목 GLB는 약 12.9 MB로 상세 화면에서 읽는다.

로컬 검증에서는 모델 검사와 Playwright 데스크톱·모바일 테스트, 프로덕션 스모크 검사를 실행한다. 모바일 에뮬레이션에서는 전신 모델 탭, 상세 화면 이동, 빠른 표시, 손등 보기, 슬라이더와 복원을 확인한다.

## 남은 검증

- [머리·목 #25](https://github.com/Yongyeon-Kim/anatomy-3d/issues/25)의 나머지 겉질과 세부 감각·신경 구조, [골반·회음 #27](https://github.com/Yongyeon-Kim/anatomy-3d/issues/27)의 독립 직장·여성 골반 모델은 추가 자산 검토가 필요하다. 목록에서 제공하는 구조의 범위는 위 표와 명세에 표시한다.
- 정렬할 수 있는 복부 피부·피하조직과 복막 전체 표면은 추가 자산 검토가 필요하다. 현재 원본에서 확인한 복막 관련 표면은 큰그물막·작은그물막·결장간막이다. 향후 층 탐색에서는 피부·피하조직의 표면 위치, 복벽과 복막의 경계, 기존 모델과의 정렬 및 사용 범위를 확인한다. 배가로근막과 배가로근의 명칭과 층 관계는 복벽 해부 자료를 참고했다. [충남대학교 배벽과 샅굴 강의 자료](https://contents.kocw.or.kr/KOCW/document/2015/chungnam/kimdongwoon/1.pdf)
- 원본 라이선스가 별도로 열거하는 뇌 백질, 귀, 콩팥 자산은 실제 적용 파일별 출처와 공개 배포 범위를 확인한다. 관련 근거는 [원본 확보 기록](13-sample-acquisition.md)에서 확인한다.
- 실물 Android·iOS 기기에서의 터치, 전송·첫 표시·부위 연속 전환·메모리 측정과 전문가 해부학·용어 검수는 [전신 검증 #30](https://github.com/Yongyeon-Kim/anatomy-3d/issues/30), [모바일 성능 #11](https://github.com/Yongyeon-Kim/anatomy-3d/issues/11), [전문가 검수 #12](https://github.com/Yongyeon-Kim/anatomy-3d/issues/12)에 남아 있다.
