# 화면 구성과 3D 조작 상태 명세

작성일: 2026-11-06. 연결 이슈: [#3](https://github.com/Yongyeon-Kim/anatomy-3d/issues/3). [스토리보드](11-storyboards.md)를 PC·모바일에서 수행하기 위한 텍스트 와이어프레임이다. 픽셀 디자인·프레임워크·실제 구현은 결정하지 않는다.

## 화면 목록

| 화면 | 포함 내용 | 연결 |
| --- | --- | --- |
| 시작 | 자유 탐색·학습·설명 준비, 최근 장면 | 부위 선택 또는 과정 목록 |
| 탐색 | 부위·계통·검색, 3D, 정보 카드 | 설명 모드·장면 저장 |
| 학습 | 목표·현재 단계, 3D, 다음 행동 | 문제·복습 |
| 설명 준비 | 장면 목록, 3D, 강조·이름 선택 | 전체 화면 발표 |
| 저장 장면 | 장면 이름·부위·모델 버전 | 열기·이름 변경·삭제 |
| 도움·정보 | 조작 도움, 출처, 오류 신고 | 현재 화면 복귀 |

## PC 탐색 화면

```text
┌ 모드: 탐색 / 학습 / 설명 ─ 부위 ─ 검색 ─ 도움 ┐
│ 부위·계통 목록 │             │ 선택 구조 정보 │
│ 표시·숨김     │   3D 화면   │ 이름·설명      │
│ 선택 구조 목록│ 방향 표시   │ 관계 보기      │
├───────────────┴─────────────┴───────────────┤
│ 회전 / 화면 이동 / 포인터  ·  앞 / 뒤 / 옆  │
│ 분리 대상: 가슴 · 간격 슬라이더 · 배치 복원 │
│ 되돌리기 · 화면 초기화 · 장면 저장          │
└───────────────────────────────────────────┘
```

분리 도구는 해당 부위가 분리를 지원할 때만 노출한다. 설명 모드에서는 좌측 목록과 우측 정보 카드를 접어 모델 영역을 넓히고, 포인터·라벨·이전/다음 장면·저장 시점 복귀를 우선 표시한다.

## 모바일 화면

```text
┌ 모드 선택 · 현재 부위 · 검색 ┐
│                              │
│          3D 화면             │
│ 방향 표시 / 현재 상태        │
│                              │
├ 선택 구조 이름 · 정보 열기 ──┤
│ 회전 · 분리 · 표시 · 더보기  │
│ 현재 도구의 조절 영역        │
│ 되돌리기 · 복원 · 저장       │
└──────────────────────────────┘
```

정보는 아래에서 여닫는 패널로 제공한다. 분리 도구를 켜면 조절 영역에 큰 슬라이더를 표시한다. 정보 패널과 조절 영역이 동시에 3D 화면을 대부분 가리지 않게 하나씩 펼친다. 발표에서는 전체 화면을 사용하고 도구 숨김·다시 표시 버튼을 고정한다. 태블릿 가로 화면은 PC 배치를 기준으로 하되 마우스 호버에만 의존하지 않는다.

## 입력 모드

| 모드 | 드래그 | 탭·클릭 | 확대 | 종료 |
| --- | --- | --- | --- | --- |
| 관찰 | 회전 | 구조 선택 | 핀치·휠·버튼 | 기본 모드 |
| 화면 이동 | 화면 내 이동 | 기존 선택 유지 | 동일 | 관찰 버튼 |
| 포인터 | 포인터 이동 또는 선·원 표시 | 표시 시작·끝 | 화면 버튼 사용 | 관찰 버튼 또는 Escape |
| 분리 조절 | 슬라이더에서만 간격 조절, 모델 위에서는 회전 | 구조 선택 | 동일 | 관찰 버튼 |

직접 장기를 당기는 모드는 첫 체험판에 넣지 않는다. 슬라이더 밖의 드래그로 장기가 우연히 이동하지 않아야 한다. 회전과 그리기는 동시에 활성화하지 않는다. 포인터·선·원 도구의 현재 상태는 텍스트와 선택 표시로 구분한다.

3D 표면에 선을 붙이는 기능은 별도 구현 검증 전까지 약속하지 않는다. 초기 임시 선·원은 화면 기준이며 시점을 변경하거나 장면을 넘기면 지운다. 포인터는 저장 장면에 포함하지 않는다.

## 복원 명령의 차이

| 명령 | 복원하는 것 | 유지하는 것 |
| --- | --- | --- |
| 되돌리기 | 직전 숨김·투명도·분리 변경 | 현재 관찰 방향과 진도 |
| 배치 복원 | 구조물 위치를 정상 배치로 | 시점·선택·숨김·투명도 |
| 화면 초기화 | 현재 부위의 기본 시점·표시·정상 배치 | 학습 기록과 저장 장면 |
| 저장 시점 복귀 | 현재 발표 장면의 저장된 시점·표시·배치 | 저장된 원본과 발표 순서 |
| 원위치 비교 | 일시적으로 분리 정도 0 표시 | 비교 전 상태를 보관 |

원위치 비교를 종료하면 비교 전 분리 상태를 되살린다. 비교 중에는 새 분리 조작·장면 저장을 잠시 제한하고, ‘비교 종료’와 ‘이 배치로 유지’를 제공한다. ‘이 배치로 유지’는 배치 복원과 동일하게 처리한다.

## 모드 전환과 문제 상태

탐색에서 설명으로 전환할 때 시점·선택·분리·표시를 유지한다. 학습 과정을 시작하면 현재 장면을 임시 보관하고 과정의 시작 장면을 연다. 과정 종료 시 탐색으로 복귀할 수 있다.

문제 상태는 ‘준비 → 답안 선택 → 제출 → 해설’이다. 제출 전 선택 변경은 허용한다. 제출 전 이름·검색·정보 카드·정답을 알려 주는 라벨은 숨긴다. 회전·확대와 필요한 구조 선택은 허용한다. 중도 종료는 미완료이며, 명시적으로 제출한 답만 기록한다.

## 저장 장면 항목

- 장면 ID·이름·작성 시각·수정 시각.
- 콘텐츠 및 모델 버전, 부위 ID, 선택 구조 ID 목록.
- 시점·확대·회전 중심, 숨김·투명도·강조·라벨 설정.
- 분리 대상 그룹과 정도, 쉬운 이름·전문 이름 표시 선택.
- 설명 묶음 ID와 장면 순서(설명 묶음에 속하는 경우).

문제 정답·학습 기록은 장면과 별도로 저장한다. 장면 저장 버튼은 퀴즈 제출을 대신하지 않는다. 게스트 기록은 기기 내에 저장하며 서버 동기화가 구현되기 전에는 다른 기기에서도 열린다고 표현하지 않는다.

## 오류·접근성 상태

| 상태 | 화면 동작 |
| --- | --- |
| 최초 로딩 | 진행 상태와 취소·설명 보기 표시 |
| 느린 연결 | 재시도와 현재 설명 유지, 무한 대기 대신 실패 상태 제공 |
| 3D 표시 불가 | 구조 목록·설명·텍스트 학습을 제공하고 3D 사용 불가 안내 |
| 저장 공간 부족 | 저장 실패 안내, 저장 완료 표시 금지 |
| 저장된 구조 누락 | 지원하는 항목만 복구하고 누락 안내, 원본 자동 덮어쓰기 금지 |
| 키보드 사용 | 화면 버튼·구조 목록·슬라이더에 순서대로 접근 |
| 색 구분 어려움 | 색과 이름·선택 윤곽을 함께 표시 |
| 애니메이션 감소 | 시점·복원 이동 효과를 줄이되 결과 상태는 동일 |

포인터를 볼 수 없어도 구조 목록과 설명에서 선택 대상을 알 수 있어야 한다. 3D 자체가 읽기 도구에서 완전히 해석된다고 가정하지 않는다.

## 검증 체크

- 세 진입점이 README·기획·스토리보드에서 일치한다.
- 20개 구조 후보 ID가 과정에서 참조 가능하다.
- 설명 모드에 퀴즈 진행을 강제하지 않는다.
- 분리·배치 복원·화면 초기화의 결과가 서로 명확하다.
- 저장 실패와 실제 저장 완료를 구분한다.
- 구현·사용자 테스트·의학 검수 완료를 문서 작성 완료와 구분한다.

이 체크는 문서 검토 기준이다. 실제 화면과 기기 동작의 통과 여부는 후속 구현에서 검사한다.
